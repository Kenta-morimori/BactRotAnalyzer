# 元TIFFから対象1個の重心を取得する

明瞭な冒頭フレームで対象内を1点指定し、固定ROI内で同じ対象の白画素重心を追跡します。
独立した抽出CLIです。通常回転解析への接続と既存キャッシュの更新は行いません。

## 実行

リポジトリ直下で実行します。既存のPython依存に加え、動画出力にはPATH上の`ffmpeg`が必要です。
対話操作にはデスクトップで利用できるOpenCVウィンドウが必要です。

```bash
python3 scripts/tiff_roi_centroid.py \
  --input data/example/tiff_frames \
  --output outputs/tiff_centroid/run01
```

1. 最初のTIFFで対象の前景内をクリックします。
2. 自動ROIを確認し、Enterで確定します。Rで矩形を引き直せます。
3. 記録ギャップの後は、再び対象をクリックします。ROIは記録全体で固定です。

ROI端への接触は欠測になり、動画に`roi_edge`と表示されます。自動拡張はしません。
必要ならROIを修正して、新しい出力先へ再実行してください。

入力は連番接尾辞`_00000.tif`を持つ単一面グレースケールTIFFのフォルダです。
TIFFタグ306の元時刻を使い、接尾辞+1を`source_frame_1based`として保存します。
時刻が読めない行の座標は欠測にします。フレームレートから元時刻を捏造しません。
単一記録を非対話で処理する場合は`--seed X Y`、手動ROIは`--roi X Y WIDTH HEIGHT`を指定できます。
`--seed`だけの非対話実行ではギャップ後は再指定待ちの欠測になるため、複数記録にはmanifestを使います。

## 固定された抽出規則

元の16bit階調を保ったまま、画像全体をOpenCVの線形補間で10倍に拡大してから閾値処理します。
閾値は試料ごとに固定し、既定値は2000です。`--threshold`で変更できます。
8近傍の連結領域を使い、3元画素未満の微小領域は除きます。穴は埋めません。

自動ROIは冒頭の連続1秒以内・最大200フレームで対象を近傍追跡し、採用領域の外接矩形を囲みます。
余白は等価半径の半分以上かつ最低2元画素です。採用20フレーム未満または採用率80%未満なら
自動決定せず、対話では手動ROIを要求し、非対話では設定エラーとして終了します。
この冒頭区間が回転範囲を代表することを仮定するため、後半を含めた動画確認が必要です。

初回は指定点を含む領域を選び、その後は最後の有効重心から初期等価半径の2倍以内を探索します。
初期面積の1/4〜2倍を候補とし、近い2候補の距離差が`max(1元画素, 初期半径/4)`未満なら曖昧とします。
前フレームの複数領域が1領域へ合流した場合と面積が過大になった場合は接触疑いとして欠測にします。
接触疑いの領域が分離するまで採用を再開せず、無関係な別領域の存在だけでは解除しません。

最後の有効位置は探索にだけ使い、CSVの欠測座標を補完しません。
分離後に近傍対応が一意なら再捕捉します。曖昧なら`ambiguous`の欠測を続けます。
対象を見直してmanifestに再指定点を追加し、新しい出力先へ再実行できます。
記録区間の変更、原フレームの不連続、非正または通常間隔の1.5倍を超える時刻差では対応を解除します。
ギャップ後の自動再同定は行いません。

この方法は位置と連結領域の簡単な対応であり、見えない間の入れ替わりを保証付きで識別できません。
初回から結合している領域や、面積変化が小さく前フレームにも分離像がない接触は検出できない場合があります。
再捕捉と接触前後は必ず動画で確認し、対象が判別できなければ欠測または再指定にしてください。
watershed、背景補正、多物体ID管理は含みません。

## 出力と座標

出力先はGit管理外の`outputs/`内に、新しいディレクトリとして作成します。
既存ディレクトリへの上書きは拒否します。実測成果物をGitやPRへ追加しないでください。

- `run.json`: 入力設定、コードのハッシュ、実行環境、完了状態、理由別件数、再捕捉位置、処理時間。
- `sampleN/setup.json`: 固定ROI、初回指定点、閾値、拡大規則、ROI決定結果、入力ハッシュ、表示階調。
- `sampleN/resolved_seeds.json`: ギャップ後を含む実際の再指定点。
- `sampleN/centroids.csv`: 元フレーム、元時刻、元タイムスタンプ、記録区間、重心、欠測理由、再捕捉フラグ、元ファイル。
- `sampleN/review.mp4`: 元TIFF、ROI内の二値マスク、選択領域と重心の重ね合わせ。
- `sampleN/presentation.json`: 動画の各フレームと原フレームの対応。ギャップ説明画面は`null`。

CSVは入力1枚につき1行を保持します。欠測の`x_px,y_px`は空欄です。
元TIFFの画素中心を整数、x右向き・y下向きとし、10倍像の白画素平均を
`native=(enlarged+0.5)/10-0.5`で戻します。ROIオフセットも加算します。
物理単位への換算、回転方向判定、角速度推定は行いません。

動画の緑枠は固定ROI、シアンは選択領域、赤十字は採用重心です。
表示は確認用に縮小・拡大しますが、重心は10倍像の白画素から計算します。
既定50fpsの動画は各元フレームを1回ずつ収録するので、200fps記録では4倍スローです。
`--video-fps`で変更でき、`--no-video`でCSVだけを作れます。
時刻とフレームのギャップには1秒の説明画面を挿入します。

## バッチ指定

```json
{
  "samples": [{
    "input_id": "synthetic-example",
    "threshold": 2000,
    "roi": [10, 10, 50, 50],
    "seeds": {"1": [30, 32], "100": [31, 32]},
    "frames": [
      {"path": "frames/demo_00000.tif", "source_frame_1based": 1,
       "time_sec": 0.0, "source_timestamp": "original timestamp", "segment_id": 0},
      {"path": "frames/demo_00099.tif", "source_frame_1based": 100,
       "time_sec": 1.0, "source_timestamp": "original timestamp", "segment_id": 1}
    ]
  }]
}
```

```bash
python3 scripts/tiff_roi_centroid.py \
  --manifest local_manifest.json --output outputs/tiff_centroid/run02
```

`path`はmanifestからの相対パスまたは絶対パスです。`roi`を省略すると自動決定します。
`seeds`は元フレーム番号を文字列キーとします。時刻不明は`null`で保存します。
`--manifest`では閾値も試料の`threshold`に指定してください。

## 検証の範囲

`tests/test_tiff_roi.py`で、自動ROI、対象指定、明るい別物体、消失・再捕捉、結合・分離、
曖昧な対応、ROI端、記録ギャップ、穴、10倍座標変換、再現性、入力非変更、上書き拒否を検証します。
動画は全フレームをデコードして対応を確認します。

円・楕円・非対称・穴・明るさ変化の合成画像では、各20固定seedについて
P95誤差0.5元画素以下かつ半径の10%以下、採用率95%以上、別物体への乗り換えなしを確認します。
これらは孤立した識別可能条件のテストであり、任意の実測接触に対する精度保証ではありません。
実測は独立した位置真値がないため、取得率と目視確認を精度の証明として扱いません。

### 実測で確認できたことと残る判断

2試料を各24,576フレーム、同じ固定閾値2000で全処理し、別実行のCSVがバイト単位で一致しました。
元フレーム・時刻を保持し、確認動画は全フレームをデコードして対応を検証しています。
全再捕捉箇所の前後画像と、旧法の取りこぼし・接触前後を同座標へ重ねて確認しました。
目視範囲で対象の乗り換えは認めませんでしたが、独立したID真値による証明ではありません。

| 集計 | 試料1 | 試料2 |
| --- | ---: | ---: |
| 新法の採用行数 | 24,380 | 24,535 |
| 新法の採用率 | 99.20% | 99.83% |
| 再捕捉回数 | 31 | 4 |
| 旧法が欠測、新法が採用 | 41 | 111 |
| 旧法が採用、新法が欠測 | 185 | 41 |

旧法の有限座標には対象以外の選択が含まれ得るので、この表だけで正確度は比較できません。
新法の欠測には接触疑いの棄却を含み、薄い周辺像との連結でも欠測になります。
不要な欠測が増えていないことの定量的な確定は残っています。
実測での同一性・位置精度は未確定部分を残すため、通常解析へ採用する判断は保留します。
実測画像・座標・詳細注釈・比較動画はローカルのGit管理外に保存します。

既存のテストAVI全10本・12,000フレームでは、通常抽出の位置・欠測・原フレーム・時刻・単位が
`dev`と一致し、独立に計算した選択領域の白画素平均とも一致しました。
