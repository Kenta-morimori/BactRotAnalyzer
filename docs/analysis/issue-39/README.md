# Issue #39: 候補中心の条件別検証（中間結果）

判定を始める前に固定した規則は[protocol.md](protocol.md)。再実行はリポジトリ直下で `python3 scripts/diagnostics/issue39_validation.py`。入力はコードに生成条件を固定した模擬重心、`data/test_data/test_1.avi` から `test_10.avi`、および `outputs/repellent-response/23/raw_centroid/2026_0802_182430.csv`。全結果は[tables/synthetic.csv](tables/synthetic.csv)、[tables/test_avi.csv](tables/test_avi.csv)、[tables/no14_windows.csv](tables/no14_windows.csv)に保存した。

## 既知中心の模擬軌道

各条件8試行、360フレーム、200 Hz。真の長半径は 0.3 µm。表の誤差は真の中心との差 / 0.3 µm の試行間 P95。中心移動条件は窓中央の真の中心との比較であり、時変中心を追えたという意味ではない。

| 条件 | 現行法 | 制約付き代数楕円 | 幾何学的楕円 |
| --- | ---: | ---: | ---: |
| 全周楕円 | 0.012 R | 0.011 R | 0.012 R |
| 細長い楕円 | 0.020 R | 0.014 R | 0.017 R |
| 厚い楕円 | 0.082 R | 0.049 R | 0.072 R |
| 方向反転 | 0.011 R | 0.011 R | 0.010 R |
| 短い弧 | 1.098 R | 0.987 R | 1.006 R |
| 停止点群 | 1.012 R | 1.003 R | 1.015 R |
| 中心の直線移動 | 0.010 R | 0.011 R | 0.015 R |
| 途中で軌道縮小 | 0.026 R | 0.016 R | 0.029 R |
| 20フレーム欠測 | 0.012 R | 0.011 R | 0.013 R |

全周条件は事前の 0.10 R、厚い楕円も 0.20 R の誤差基準を満たした。方向反転の模擬軌道では11フレーム平滑化後、真の反転前後（境界±10フレームを除く）の方向不一致と余分な符号切替は全試行で0だった。ただし、これは一定中心を全窓に当てた容易な反転例であり、反転と同時に軌道や中心が変わる例を保証しない。

**短い弧と停止点群は採用条件に不合格。** 制約付き代数法は両条件の全8試行で `computed` を返しながら約1 R の誤中心となった。幾何学的方法も中心誤差を改善せず、計算状態だけでは誤中心を確実に棄却できない。平行移動試験で代替2法の中心差はほぼ0（最大 6×10⁻⁸ R）、現行法は最大0.305 R。原点不変性は必要だが、停止点群の中心を正しくする十分条件ではない。

## 実 AVI で確認できたこと

参考の頑健円も同じ入力で比較した。細長い楕円の8試行中2試行で探索境界に達し、その中心誤差は約1 R。円はこの軸比条件の安定した代替ではない。短い弧・停止点群では円も真の中心から約1 R離れ、楕円の情報不足を解消しない。

`test_data` の10本は各1200フレーム・200 Hzで、重心未検出は0。3楕円法と参考の円は全体窓で計算成功し、ブロック除外時の中心変化は最大0.012 R、保留残差 P95 は0.087–0.251 Rだった。中心を使わない x/y の四分位相指標は0.998–1.000、ピークエネルギー率は0.871–0.977。これらは周期的な軌道の確認には使えるが、真の中心や反転時刻の独立検証ではない。10本に停止・反転が含まれるという証拠も得ていない。

No.14 は原 AVI から保存した重心のフレーム番号1–18432との一致を確認した上で、5つの代表開始時刻から5.080367秒の窓を再評価した。15.781秒では現行法が実楕円を返さず、代替2楕円法の保留残差は0.576–0.847 R。20.789秒では幾何学的方法が境界に到達し、代替2楕円法の保留残差は0.802–0.906 R。38.318秒では3楕円法の保留残差は0.682–0.758 R。64.862秒では幾何学的方法の保留残差が0.444 Rで現行0.496 Rより小さいが、中心真値はない。82.500秒以降は従来の中心保持に該当し、この再フィットを正解とは扱えない。

## 中間判断と残りの検証

第1段階では、停止・短い弧を確実に無効化しつつ、十分な重心軌道を残す採用規則は未確立だった。第2段階の判定規則を未使用試行で検証した結果と最終判断は後述する。計算上良い楕円が返ることと、重心軌道から中心が支持されることを分ける。

窓幅（2・5・10周期）と前向き/中央位置、変化境界、幾何学的方法の初期値・探索範囲・反復上限は以下で比較した。残る論点は実データでの周期推定と変化点、無効窓・欠測・終端の出力契約、角速度平滑化の時刻精度。No.14 の実データでは結果を外的妥当性の補助として使い、真値誤差は主張しない。採用法が決まらなければ本解析は変更しない。

## 無効判定規則の前向き試験

[第2段階の固定規則](protocol.md)を、未使用seed 4000–4029で評価した。再実行は `python3 scripts/diagnostics/issue39_gate_holdout.py`。全行は[模擬試験表](tables/gate_holdout_synthetic.csv)と[実AVI表](tables/gate_real_samples.csv)。各条件は30試行×代替2法で、表は各手法の合格試行数を示す。

| 模擬条件 | 制約付き代数楕円 | 幾何学的楕円 | 解釈 |
| --- | ---: | ---: | --- |
| 全周楕円・円・細長い楕円・厚い楕円 | 各30/30 | 各30/30 | この模擬分布では保持。 |
| 方向反転・中心移動・半径変化 | 各30/30 | 各30/30 | 中心が正しいという追加証明ではない。 |
| 短い弧・停止点群・半分停止・直線往復 | 各0/30 | 各0/30 | 今回の負例を棄却。 |
| **低振幅の周期的な揺れ** | **30/30** | **30/30** | 停止中の重心揺れでも合格する反例。 |

低振幅反例は、停止した対象の重心が半径0.008µmで周期的に揺れる設定であり、対象の回転は与えていない。それでも x/y 位相、周波数、楕円残差、再推定幅が回転と同様の値になる。**同一の重心座標は、対象の軌道運動と撮影台などの周期変位で生成できるため、重心だけでは測定信号の原因を一意に識別できない。** この試験は停止時の実際の撮影ノイズ分布を推定したものではない。したがって「低振幅なら停止」と一般化もしない。

`test_data` の10本は両候補とも合格。No.14 の代表5窓では、15.781/20.789/38.318秒開始は両候補が不合格、64.862秒開始は両候補が合格、82.500秒開始は幾何学的方法だけ合格。ただし最後は従来の中心保持区間に重なり、新規フィットの成功を終端中心の真値確認に使わない。規則の閾値は探索結果を見て置いており、この実データでの分離を独立な正解率とは呼ばない。

ユーザーの定義では対象は**重心軌道の角速度**であり、菌体の姿勢角速度ではない。この前向き試験は中心の数値的な信頼性を絞るが、座標上の周期揺れが撮影・検出由来かまでは保証しない。#40 に渡すには、出力を「重心軌道の条件付き角速度」と明確にし、無効窓の扱いと下流CSVの欠測契約を検証する必要がある。

## 窓幅と時間位置

`python3 scripts/diagnostics/issue39_window_study.py` で、既知周期60フレームの軌道1200フレームを5試行ずつ作り、2・5・10周期幅、前向き/中央配置、7つの評価時刻を同じ3手法で比較した。[全試行表](tables/window_study.csv)は要求幅に足りない窓を `incomplete_window` として残す。以下の誤差は真の長半径0.3µmで正規化した中心誤差で、制約付き代数楕円の計算成立した窓を集計した。窓は大きく重なるため、行数を独立試行数とは扱わない。

| 条件 | 2周期 | 5周期 | 10周期 |
| --- | ---: | ---: | ---: |
| 一定中心・中央窓、P95 | 0.025 R | 0.016 R | 0.011 R |
| 線形中心移動・中央窓、P95 | 0.025 R | 0.016 R | 0.010 R |
| 線形中心移動・前向き窓、P95 | 0.056 R | 0.107 R | 0.207 R |
| 中心が0.4 R飛ぶ境界をまたぐ中央窓、P95 | 0.209 R | 0.199 R | 0.201 R |
| 同じ境界をまたぐ前向き窓、P95 | 0.314 R | 0.358 R | 0.378 R |
| 同じ楕円上で方向反転する窓、P95 | 0.020 R | 0.014 R | 0.008 R |

一定中心では幅を伸ばすとノイズが平均化される。線形移動中の前向き窓は**窓の未来側平均中心を開始時刻へ割り当てる**ため、長いほど時刻位置の誤差が増える。中央窓はこの模擬線形移動ではほぼ相殺されるが、中心が飛ぶ境界をまたぐ窓では両配置とも事前0.10 R予算を超えた。反転だけで同じ軌道をたどる場合、反転をまたぐ窓の中心誤差は小さい。**反転点で無条件に窓を切る必要はなく、同時に中心や軌道形状が変わるかを分けて判定する。**

停止後だけを含む窓では、制約付き代数法は計算成立しても中心誤差中央値が約0.99 R。短く切るだけでは停止点群の中心を救えない。以上は既知周期を用いた制御試験であり、実データの周期推定、中心変化点の発見、最適窓幅はまだ決めていない。実データでは #38 の4幅比較と併せ、変化点をまたがない窓と、情報不足なら無効にする規則が必要になる。

## 角度差分に残る誤差

`python3 scripts/diagnostics/issue39_angle_sensitivity.py` は、一定中心・厚い軌道・反転・中心移動の既知軌道で、フレーム差分による符号と速さの誤差を調べる。比較には**真の中心そのもの**も含める。11フレームのSavitzky–Golay平滑化は原因分離の参考であり、採用法・許容時間遅れではない。[模擬試験表](tables/angle_synthetic.csv)、[No.14参考表](tables/angle_no14.csv)に全結果を保存した。

| 模擬条件（8試行の中央値） | 真の中心・生の差分 | 制約付き代数楕円・生の差分 | 真の中心・11フレーム平滑化 |
| --- | ---: | ---: | ---: |
| 全周楕円：余分な符号切替 | 131回 | 130回 | 0回 |
| 方向反転：真の1回を超える符号切替 | 約130回 | 約129回 | 0回 |
| 厚い楕円：余分な符号切替 | 229回 | 230回 | 約70回 |

模擬楕円では真の中心でも生の角度差分が多くの誤反転を作る。これは設定した重心ノイズと200 Hzの1フレーム差分に由来し、中心法だけを替えても解消しない。平滑化はこの模擬条件の符号誤りを減らすが、厚い軌道ではなお残る。平滑化の窓幅を本解析へ採用するには、反転時刻の遅れと速度振幅の変化を別途定量化する必要がある。

追加の未使用seed 4100–4129で、重心座標を 1・5・11・21・41フレームの窓で平滑化してから角度差分を計算した。[窓幅感度表](tables/angle_smoothing_sensitivity.csv)に真の中心と制約付き代数楕円の全試行を保存した。真の中心での余分な符号切替の中央値は、全周楕円で 138→26→0→0→0 回、厚い楕円で 230→151→62→6→0 回。反転条件では11フレーム以上で全30試行の余分な切替が0回だった。既知の反転境界から最も近い検出切替までの絶対時刻差P95は、11フレームで5 ms、21フレームで10 ms、41フレームで5 ms。ただし最も近い切替だけの評価であり、別の急変条件や実データへ一般化できない。ユーザーは許容時刻差をまだ定められないため、平滑化幅の採用判断は保留する。

No.14 の64.862秒開始窓では、3楕円法の生の符号切替が357–359回/約1000フレーム、保存済みの時変中心でも361回だった。11フレーム平滑化後はそれぞれ100–102回。保存中心と候補中心の差は小さいが、独立した反転時刻はないので、これらをすべて誤りとも真の反転とも数えない。保存中心は #38 の確定済み重心と原フレームごとに一致を確認して比較した。15–40秒の窓は中心の信頼性も低く、角速度の大きさの差を方法優劣の根拠にしない。**#37 の角速度異常は中心推定と角度差分を別々に評価する必要がある。**

## 幾何学的方法の数値設定

`python3 scripts/diagnostics/issue39_geometric_sensitivity.py` で、初期中心（代数楕円/座標中央値）、探索範囲（0.75/1/2倍）、最大評価回数（40/80）を12通り比較した。[全設定表](tables/geometric_sensitivity.csv)に中心と計算状態を保存した。模擬条件は各4試行、No.14は3窓。中心変化量は各入力の標準設定（楕円初期値、1倍、80回）からの距離を観測半径で割った値。

| 条件 | `computed` / 全設定 | 最大中心変化 |
| --- | ---: | ---: |
| 全周楕円 | 48/48 | 0.000001 R 未満 |
| 厚い楕円 | 48/48 | 0.000002 R 未満 |
| 短い弧 | 12/48 | 1.26 R |
| 停止点群 | 4/48 | 1.70 R |
| No.14 20.789秒 | 0/12 | 1.21 R |
| No.14 64.862/82.500秒 | 各12/12 | 各0.000005 R 未満 |

この設定範囲では、全周軌道の解は安定する一方、情報不足の点群では探索境界への到達と中心の大きな変化が一致した。幾何学的方法の残差が低いだけで情報不足を救ったとは判定しない。未使用30試行の既知中心誤差P95は、制約付き代数楕円/幾何学的楕円で、全周楕円 0.011/0.011 R、厚い楕円 0.053/0.062 R、細長い楕円 0.015/0.017 R、半径変化 0.014/0.018 R。制約付き法はこれらの模擬条件で少し良く、実AVIの保留残差中央値は幾何学的方法が少し低い（`test_data` 0.145/0.140 R、No.14 の代表5窓 0.758/0.576 R）。後者のNo.14集計には不合格窓も含み、真の中心誤差を示さない。

## #39 の選定

**制約付き代数楕円を、判定規則に合格する窓だけに使う第一候補として選ぶ。** 現行の非拘束楕円は平行移動で最大0.305 Rの中心差と非楕円を返した。制約付き法は試験した全周・反転・厚い楕円の事前誤差予算を満たし、未使用30試行の各陽性条件を全件保持、短い弧・停止・部分停止・直線往復を全件棄却した。幾何学的方法も同じ判定規則を通ったが、既知中心に対する厚い楕円・軸比の誤差は制約付き法がやや小さく、幾何学的方法は情報不足の窓で探索設定に依存した。実AVIの保留残差は幾何学的方法がやや低いので、制約付き法が実物の真の中心に近いとまでは主張しない。

適用条件は、欠測なし、中心を使わない四分位相指標0.8以上、ピークエネルギー率0.15以上、4ブロックの観測半径の最小/最大0.25以上、全体と4つのブロック除外楕円が計算成立、保留残差P95/Rが0.55以下、中心再推定幅0.10R以下、平行移動による中心差0.01R以下。**不合格窓では中心を返さず、角速度も有効値として扱わない。** 閾値は今回の模擬分布での探索値であり、実データの真値保証ではない。低振幅の周期揺れはこの規則を通るため、画像・撮影系の情報がない場合は測定由来の周回を識別できない。この限界を出力の意味と共に明記する。

実装で残る設計は、実データの局所周期と変化境界による窓割り、欠測と終端での無効状態の伝播、既存CSV列の互換性である。角速度の生差分は真の中心でも誤符号を多発させるため、中心置換だけで #37 の全症状が消えるとはしない。反転時刻の許容差が未定のため平滑化幅は選ばず、#40 では中心推定の変更と角速度差分の既知の限界を分けて扱う。
