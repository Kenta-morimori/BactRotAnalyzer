# Issue #39: 回転中心候補の事前評価規則

この規則は #39 の新しい比較結果を計算する前に定める。#38 の探索結果を再利用するが、No.14 の既存図表から数値を調整しない。中心の計算成功と物理的妥当性は区別する。

## 入力と比較対象

- 同一の元重心を、現行の非拘束代数楕円、制約付き代数楕円、頑健な幾何学的楕円へ入力する。参考として円も表示する。
- 既知中心の模擬軌道を主試験とする。回転軸比、短い弧、停止、方向反転、中心の移動、軌道サイズ変化、欠測を一つずつ変え、元フレーム番号を保持する。
- `data/test_data` の AVI と No.14 の原 AVI から得た重心を外部確認に用いる。AVI には中心・向き・反転時刻の独立真値がないため、それらの誤差や正解率は報告しない。
- 観測窓は固定幅の前向き窓・中央窓とし、窓幅は回転周期の 2・5・10 倍を比較する。周期は中心を差し引かない x/y のスペクトルから推定し、周波数が確認できない区間には幅を自動適用しない。既存 5.080 秒幅は比較基準として残す。

## 事前の合否基準

ここでの R は模擬軌道の真の長半径。中心誤差、中心変化、角度差分を同一のフレーム軸で計算する。
0.10 R と 0.20 R はこの検証に置く暫定的な誤差予算であり、生物学的に許される角速度誤差ではない。後者を厚い軌道に緩めても、短い弧・停止の約 1 R の誤中心とは区別できるように設定した。角速度に対する許容差は別途検証する。

| 条件 | 採用候補に必要な結果 |
| --- | --- |
| 一定中心、全周、十分な点数 | 中心誤差の P95 が 0.10 R 以下。平行移動後の中心差は 0.01 R 以下。 |
| 厚い軌道・軸比の大きな楕円 | 中心誤差の P95 が 0.20 R 以下。現行法より悪化しない。 |
| 方向反転 | 真の反転前後で周回方向が一致し、不要な符号切替を現行法より増やさない。反転をまたぐ窓を単一方向と誤記しない。 |
| 短い弧・停止・欠測 | 物理的中心を特定できない区間を採用しない。計算成功のみで合格にしない。欠測行を時間軸から詰めない。 |
| 移動する中心・軌道サイズ変化 | 真の時変中心との差を報告し、一定中心の合格を流用しない。窓位置と幅の選択が境界をまたぐ場合を明示する。 |
| 幾何学的楕円の数値安定性 | 初期中心、探索範囲、反復上限を変えた中心差を報告。境界到達や未収束を物理的情報不足と同一視しない。 |
| 実 AVI | 入力フレーム・重心の対応、各候補の計算状態、保留時間ブロック残差と再推定幅、中心非依存の周期・位相を記録する。真値なしの改善は採用の補助証拠に限る。 |

全条件を満たす採用規則を見つけられない場合、#40 の本解析変更は開始しない。満たす条件が限定される場合は、その条件でだけ使う規則と無効状態を先に明文化する。中心欠測の補完は、真値付きの欠測・停止・終端試験で角度誤差を評価できるまで保留する。

## 出力

条件ごとの中心誤差、角度・角速度、計算状態、棄却状態、保留ブロック残差を表と図で残す。判定に使った閾値は事後に書き換えず、見直す場合は別版として理由と結果を併記する。
