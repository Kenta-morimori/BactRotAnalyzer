# Issue #40: 条件付き重心軌道中心の解析接続

## 実装

`utils/functions/validated_rotation_center.py` は、中心に依存しない局所 x/y スペクトルから周期を推定し、5周期相当の中央窓を0.2秒ごとに評価する。窓幅は60フレーム以上・5秒以下とし、時間の欠落・逆行や重心欠測があれば棄却する。中心は #39 で選定した制約付き代数楕円と固定済み判定規則に合格した窓からだけ採用する。#40 では中心急変をまたぐ窓への対策として、窓前半と後半の中心差が観測半径の0.22倍を超えた窓を棄却し、この条件が隣接2窓以上続く箇所の周辺半窓幅も無効化する。合格中心は評価時刻の周囲0.2秒のフレームに割り当て、隣の無効窓や未評価の端へ持ち越さない。生の重心と時刻は詰めずに元のフレーム順で保持する。

`scripts/04_repellent_response_analysis.py` の既定 `--center-estimator validated` はこの経路を使う。従来経路は `--center-estimator legacy` で再現でき、`--post-rise-center-mode` は従来経路だけに適用する。既存の `center_coordinate.csv`、`angle_time-series.csv`、`angular-velocity_time-series.csv` の列名と行対応は変えない。追加の `00_all_rotational_analysis/center_coordinate/center_assessment.csv` には試行ごとの窓・合否・理由を記録する。停止時刻が決まっている場合、その時刻をまたぐ窓は使わず、停止後の中心は欠測にする。無効中心の前後にある角速度区間は欠測となり、方向切替回数は欠測をまたいで符号をつながない。

## 再現検証

`python3 scripts/diagnostics/issue40_integration_check.py` は、既知中心の模擬軌道、`data/test_data` 10本、No.14 の設定済み解析範囲（原 AVI の2049–16384フレーム）を同じ経路で評価する。[全結果](tables/integration_summary.csv)にフレーム分母・採用数・窓数を保存した。No.14 は保存済み元重心を使用し、実データの真の中心誤差は計算しない。

| 入力 | 有効中心フレーム | 既知中心誤差 P95 |

前半/後半の中心差0.22Rと周辺半窓幅の無効化は、中心が0.4R急変する探索例と線形移動例を見てから定めた**#40 追加規則**であり、#39 の事前判定規則へ遡って含めない。`python3 scripts/diagnostics/issue40_change_holdout.py` は未使用seed 4700–4729の各30試行を再評価し、[全試行表](tables/change_holdout.csv)に保存した。0.4R中心急変例では境界前後200フレームの有効中心は全試行で0、採用フレームの中心誤差P95の試行間P95は0.017R。安定周回・厚い楕円・反転・線形移動は、各試行で少なくとも920・920・840・920フレームを保持し、それぞれの中心誤差P95の試行間P95は0.015・0.075・0.016・0.030Rだった。これは単一の急変幅とノイズ分布に対する結果で、未知の変化点への保証ではない。

模擬データで方向反転をまたぐ中心は真の中心に近いが、生の角度差分には反転前後にも多くの細かな符号切替が残る。真の中心でも同じ問題が発生することを #39 で確認済み。したがって、この変更は**中心推定と無効区間の伝播**を実装するものであり、符号揺れの解消を主張しない。反転時刻の許容差が未定のため、平滑化は導入していない。

No.14 の82.5秒以降は、従来処理が窓不足で中心を保持した区間に重なる。今回の一部窓が判定を通っても、実際の回転または撮影・検出由来の周期変位かは確認できない。撮影系の周期揺れと重心軌道運動は重心座標だけでは区別できない。実データの有効割合は #39 の模擬分布で固定した判定閾値と窓配置に依存し、真値付きの正解率ではない。

## 互換性と確認範囲

テストでは、模擬1200フレームから既存の角速度解析とCSV保存まで実行し、中心CSVの `No.1_x` / `No.1_y`、角速度CSVの `No.1`、角速度行数1199、停止後・未評価端の欠測、判定表の追加列を確認した。全区間が不合格の試料も同じ角速度CSVに欠測のまま残り、判定行が0件でも判定CSVの見出しを出す。全52テストが通過した。`data/test_data` 10本のAVIは中心抽出から窓判定まで実行した。No.14 は保存済み重心を使った窓判定であり、11 GB のday 23原データから全サンプルのTIF背景解析を再実行したものではない。
