## 評価方法

現行の FFT 設定で得た窓幅を維持し、20 フレーム間隔で窓を評価した。隣接窓は重なるため、以下の件数は独立した試行数ではない。[No.10 の窓別数値](no10_windows.csv)、[No.14 の忌避応答系列](no14_windows.csv)、[No.14 の全体解析系列](no14_initial_windows.csv)

- 現行法と同じ二次式 (Ax^2+Bxy+Cy^2+Dx+Ey=1) を重心に当てはめ、楕円の中心・軸を求めた。楕円が成立しない場合は `fit_failed` とし、窓を集計から除外しなかった。
- 楕円上の最近点までの二次元距離の 95 パーセンタイルを、窓内の重心から保存中心までの距離の中央値 (R) で割った。保存中心へ楕円を平行移動した場合の残差も別に算出した。円軌道は仮定しない。
- 各点の中心周りの角度から最大の空白角を求めた。往復で同じ弧をたどっても被覆角は増えない。ただし中心付近の散乱点でも見かけ上 360 度近くなるため、被覆角は残差と併せて読む。
- 時間順の 4 ブロックのうち 1 ブロックずつ除外して中心を再推定した。各中心の標準偏差（x、y 別）と、全点からの中心との最大二次元距離を (R) で規格化した。デザイン行列の条件数は座標を窓内で中心化・スケール化して算出した。
- 診断ラベルは探索用の目印とした。被覆角 <180 度または中心の最大変化 >0.25R は `center_unidentifiable`、楕円残差 >0.20R は `nonelliptic_or_noisy`、安定したフィットで保存中心との差 >0.25R は `saved_center_displaced` とした。残りで被覆角 <270 度または条件数 >10⁴ なら `review`、それ以外を `supported` とした。このしきい値を #39 の手法採用基準には使わない。

全体解析の補正前後の中心も[時系列図](no10_overview.png)・[No.14 時系列図](no14_overview.png)に表示した。これは忌避応答段階とは別の窓幅で推定した中心なので、忌避応答段階の補正前中心として扱わない。全体解析で補正されたフレームは No.10 が 276、No.14 が 333。まれに極端な補正前中心があり、補正量の最大はそれぞれ 32.4、169.0 だった。

**No.10:** 10.02–10.65 秒（原動画 2001–2127 フレーム）は被覆角 345 度、中心の再推定差 0.035R、ブロック除外による最大変化 0.024R。保存中心は比較的再現されるが、楕円残差の 95 パーセンタイルは 0.237R で、軌道の厚みは無視できない。[代表窓](no10_windows.png)

77.94–78.57 秒は被覆角 185 度、ブロック除外による中心変化 2.34R、保存中心と再推定中心の差 1.65R。重心が狭い領域に集まり、中心を一意に決めにくい。保存中心は **80.844 秒（解析インデックス 15040）から動画終端まで 3392 フレーム連続で固定**される。この時刻は既存の `rise_summary.csv` の自動停止時刻と一致する。89.96–90.59 秒には再び明瞭な軌道があるが、保存中心は固定されたままで、再推定中心との差は 0.73R。楕円残差は再推定中心で 0.112R、保存中心に移すと 0.79R。軌道の継続は[原動画フレーム](no10_video_frames.png)でも確認できる。

その 89.96–90.59 秒の重心から角度を試算すると、固定された保存中心では正味 −0.04 回転・角速度の符号変化 26 回、同じ窓の再推定中心では正味 −8.07 回転・符号変化 4 回となった。[計算表](no10_angle_sensitivity.csv) これは中心選択への強い感度を示す比較であり、再推定中心による反転回数を確定値として採用するものではない。

**No.14:** 忌避応答段階の 35.01–38.86 秒（原動画 5889–6656 フレーム）では 768 点あるが、楕円中心から見た被覆角は 41 度、ブロック除外による中心変化は 3.83R。点数だけでは中心を拘束できない。[代表窓](no14_windows.png) 同じ区間を全体解析の重心で評価すると被覆角 356 度、楕円残差 0.31R、保存中心と再推定中心の差 1.00R となる。入力重心の相違で診断が大きく変わる。[全体解析側の代表窓](no14_initial_windows.png)、[原動画フレーム](no14_video_frames.png)

No.14 では保存中心が正しいとは確認できず、重心座標の生成段階または参照データの対応を先に調べる必要がある。散乱点の多い区間では楕円残差が大きく、中心が滑らかに見えるだけでは軌道中心を支持できない。角速度の符号変化を反転の証拠として扱わない。[角度感度の参考値](no14_angle_sensitivity.csv)

## #39 に渡す検証仮説

1. No.10 は自動停止後に中心を固定する処理が、再開した回転の角速度を歪める。停止・再開をまたいでも、回転が観測できる区間では中心を更新できる方法を比較する。
2. No.10 の 75–82 秒と No.14 の 30–40 秒では、軌道の一部だけ、または散乱点から楕円中心を求めると不安定になる。反転点で分割する方法や局所フィットは、二次元残差だけでなく中心の再現性・被覆角で評価する。
3. No.14 の旧二系列差は、切り出し後に加算した旧中心の 2,048 フレームずれで説明できる。今後は原 AVI から一度だけ保存した重心を用い、旧系列と AVI 局所座標との位置差は別問題として扱う。

**限界:** 中心の真値はない。窓が重なり、診断のしきい値は探索用である。AVI の局所画像と旧保存座標の位置合わせにも残差がある。旧系列間の差の直接原因は判明したが、旧系列と現 AVI の座標原点・軌跡形状の差、および中心の変化のうち実際の試料移動による部分は未確定である。
