# Issue #38：重心・回転中心の評価

**最新の判断:** [元画像・軌道サイズと4窓幅の評価、merge・引き継ぎ条件](reports/no14_window_width_assessment.md)を追加。5.080秒は比較基準として維持するが、最適幅とは認定しない。 楕円を基本モデルに、制約付き代数法と幾何学的方法を複数候補として残す。[楕円中心の実データ評価とmerge条件](reports/no14_ellipse_assessment.md)を参照。円は参考比較であり、円軌道の物理的妥当性を示すものではない。

対象は **No.14 `2026_0802_182430.avi`**。確定済み重心を入力とした評価の結論、中心算出法の変更候補、補完についての決定状況をまとめる。中心の真値は独立に測定できていないため、支持の根拠は画像との整合性と再推定の再現性である。

## 結論と読む順序

1. **[重心の確認](reports/no14_centroid.md)**：標準法で原動画18,432フレームから一度だけ抽出した重心を共有する。旧二系列の差の直接原因は、旧中心を加算した際の2,048フレームずれだった。
2. **[画像・重心・現行中心の照合](reports/no14_image_trajectory.md)**：5区間・計5,074フレームの再測定は保存重心と一致し、輪郭未検出・複数輪郭・端欠けは0。15.78秒、20.79秒、38.32秒開始窓にはフィット起因の疑いがある。64.86秒開始窓は整合性を暫定支持し、82.50秒以降は中心保持のため判定不能。画像と軌跡の対応図・連続GIFを掲載。
3. **[楕円中心の実データ評価とmerge条件](reports/no14_ellipse_assessment.md)**：同じ134窓で3つの楕円法を比較し、初期値・探索範囲への感度、代表5区間の支持状況を示す。後半では幾何学的楕円の保留残差が現行法より約7.6%小さく、中心は再現される。序盤・40秒前後には問題が残る。元の5手法と補完比較は[比較記録](reports/no14_center_alternatives.md)に保存。

4. **[元画像・軌道サイズと窓幅の評価](reports/no14_window_width_assessment.md)**：原画像14,336フレームと中心を引かない点群サイズ、1.270/2.540/5.080/10.161秒の3法を比較。40秒前後のサイズ・輪郭変化と序盤の幅依存を記録し、後半の再現性を暫定支持する。mergeは分析の完了、最終手法・窓幅・無効判定・補完規則は#39で決める。

詳細な現行窓ごとの数値・探索的分類は[現行中心の評価](reports/no14_center_evaluation.md)を参照。偏角から求める周回・方向指標は中心に依存するため、それだけで停止や反転を確定しない。

## 回転中心算出法：必要な見直しと未決定事項

| 項目 | 現在の判断 |
| --- | --- |
| 原点依存の非拘束代数フィット | 見直しが必要。単に中心化するだけでは保留残差は改善しない。 |
| 有効性を確認しない中心の採用 | 実楕円不成立・未収束・境界到達を記録し、中心を確認できない窓を明示する必要がある。 |
| x・y別の外れ値補正 | 補正後の滑らかさを妥当性の根拠にせず、元の推定と補正値を区別する必要がある。 |
| 終端の中心保持 | 新しい測定として扱わず、保持区間であることを明示する必要がある。 |
| 次の比較候補 | 楕円制約付き代数法、およびそれを初期値とする頑健な幾何学的楕円。円は参考比較。現行幅を基準に4幅の感度比較を行った。 |
| 採用判断に必要な情報 | 保留時間ブロックへの残差、中心の再推定幅、収束・境界到達、中心に依存しない時間方向の軌道情報。 |
| 未決定 | 楕円推定法の最終採用規則、中心を無効にする定量基準、窓幅・時間位置の選択規則、移動する中心モデルの必要性。 |

**本解析の中心算出法・角速度・反転判定は変更していない。** 楕円を基本モデルとし、円は参考比較として残す。停止した模擬点群でも再現性の高い誤った中心が得られたため、中心の再現性と角度被覆だけでは採用できない。

## 補完：対象と閾値

| 項目 | 現在の状況 |
| --- | --- |
| 比較済みの対象 | 後半65秒以降の比較的安定した区間で人工的に隠した、頑健円による推定中心列。 |
| 比較した方法 | 両側の中心を用いた線形補完。中心サンプルを0.5–4秒相当隠して比較した。 |
| 未検証の対象 | 元重心の欠測、停止、フィット破綻、終端保持。 |
| 本解析での補完対象 | 未確定。初期・40秒前後の破綻や終端保持への適用根拠はまだない。 |
| 補完の採用閾値・許容誤差 | **未定義。** 指定どおり数値を設定せず、比較結果のみを示す。 |
| 270°・0.25Rなど | 探索用の診断目印。補完の採用基準ではない。 |

比較は**大きく重なる5.08秒窓の推定中心列の再現試験**であり、元重心が欠測した場合の精度や真の中心・角速度精度を保証しない。中心差と偏角差の分布は[比較レポート](reports/no14_center_alternatives.md#4-補完の比較許容誤差は設定しない)と[全試行表](tables/no14_center_interpolation_trials.csv)に残した。実データのRは、窓内のx/yの5–95%幅の大きい方の半分。

## 次に検証すること

1. #39のテスト動画で制約付き代数法・幾何学的方法を同じ重心から比較し、各候補の適用条件を検証する。
2. 中心を引かないx/yの周期性・位相関係・変位を調べ、停止や情報不足を中心の再現性だけで判定しない。
3. 各時間ブロック単独でも軌道が十分な場合に、実際の中心移動とフィットの揺れを区別する。
4. 補完は別試料・実際の欠損形態と角速度への感度を比較してから判断する。今回の比較から採用閾値は決めない。

## mergeの区切り

分析の完了で判断する。支持できる代替法が得られない場合も理由と再現可能な比較を残せばmerge可能とし、最終選定は#39で行う。入力対応、比較図・表、再利用可能なAPI、計算確認、既存テスト・CI、引き継ぎ資料を確認する。候補が計算上成立したことを物理的な採用基準にしない。

今回追加したmerge条件は、4幅の比較・元画像/点群サイズの記録・前向き窓の時間解釈・不完全窓の明示。最適な窓幅の決定は#39へ渡す。[確定した条件と未決定事項](reports/no14_window_width_assessment.md#merge引き継ぎ条件の確定)を参照。
