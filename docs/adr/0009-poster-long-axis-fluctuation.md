# ADR 0009: ポスター解析の長軸角と揺らぎ対照

## 状態

2026-11-13 採用。Issue #81。

## 判断

ポスター用テザードセル解析は、AVIの最大外輪郭を既存の二値化・面積重心規則で測り、`cv2.fitEllipse` の長軸角を主角度とする。OpenCVの返す楕円軸の長短を確認して長軸を選び、180°周期の角度差を隣接する有効フレームだけで取る。画像座標はy下向きなので、出力する角速度はCCW正に変換する。欠測・時刻gapをまたいで角度や角速度を接続しない。

重心軌跡から得る周回角と角速度は比較測定とし、全有効重心への単一円フィット中心を使う。この中心は軌道全体の比較用であり、ドリフト・部分弧・停止の真の中心を保証しない。長軸角、周回角、合成真値は別列に保存する。

揺らぎは既存のGaussian重み付き `SD(abs(角速度))/Mean(abs(角速度))` を各原観測時刻中心の窓で計算する。窓幅は0.1/0.2/0.5/1.0/1.5/2.0秒。窓に欠測またはgapがあれば欠測にする。有効な揺らぎ系列全体でz-score標準化し、最長の連続有効区間に既存FFT関数を適用する。各細胞を日付＋No.の1枚のPNGにまとめ、6窓幅のSD/Mean・標準化系列・FFTを重ねる。全幅の数値系列・FFT・使用区間は対応する表に保存する。条件別ディレクトリは作らない。

合成対照では、既知の角速度から角度を積分し、半径0.5 µmの画像座標の重心軌道を生成する。周期成分＋白色角速度ノイズと、ゼロ平均の白色角速度ノイズのみを別モデルとし、座標へ独立した測位ノイズを加える。生成長軸角と座標から同じ手順で角速度・揺らぎを再推定し、真値を保持する。200/250 Hz、6秒、seedとノイズ設定を明記する。乱数のみの対照は40 seedの分布も算出し、単一seedの偶然ピークを評価する。

## 代替案

- 既存のグローバル設定を一時切替して標準CLIを再実行する案は、欠測後の長軸角が回復しないことと、通常出力の上書きがあるため採らない。
- 重心周回角を主角度とする案は、今回の生物学的問いでは菌体長軸の向きを主とするユーザー指定に合わないため比較測定にする。
- 長軸角の180°対称性を頭尾判定で解消する案は、頭尾を識別する入力・根拠がないため採らない。

## 結果と限界

長軸角からは隣接フレーム間で90°以上の真の回転を一意に復元できない。楕円が円に近い・輪郭対象が違う・短い観測では角度や中心が不安定となる。有限の出力は正しい対象・物理的回転を保証しない。揺らぎFFTのピークは入力角速度の変調周波数と一致するとは限らず、特に窓内SDは高調波を生じ得る。6秒の記録と0.1–2.0秒窓では低周波分解能に限界がある。合成の長軸角は生成真値から作り、画像の楕円フィット誤差を加えていない。白色乱数の強度も実測ノイズへ校正していないため、乱数のみのピーク分布を実測の有意確率として使わない。純粋乱数モデルは無回転に近く、軌跡の部分弧からの円中心は不安定になり得る。

3日付の各10 AVIは同一条件の別細胞として提供された。ただし2026-11-13の入力同一性確認では、20231005と20231107の各No.7–10が日付内で完全一致するため、独立した細胞として数えない。ユーザー確認によりNo.8–10は当時の解析用複製であり、両日付のNo.1–7と20230607のNo.1–10、計24細胞を解析する。いずれも独立した実験反復とみなさず、生物学的採否・条件差の統計的主張には菌株、誘導条件、対照群と実験日ごとの対応確認を要する。

## 検証

合成画像でOpenCV楕円角と長軸変換を照合する。合成角速度の真値と長軸/周回角からの推定値を比較し、欠測後の回復、gapをまたがない処理、CCW符号、揺らぎFFTの有効区間をテストする。実測はローカルの図・CSVで対象、長軸の形状、欠測率、ピークの安定性を確認し、実測成果物をGitHubへ載せない。隔離worktreeからの実行でも出力先に非公開の実行履歴を複製する。
