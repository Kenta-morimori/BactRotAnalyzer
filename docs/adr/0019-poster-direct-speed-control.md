# ADR 0019: 独立速度ノイズ対照は角速度を直接解析する

## 状態

2026-11-14 採用。Issue #82、PR #83。ADR 0017の `random_speed_noise` における角度積分・長軸角からの再差分を置き換える。実測と `constant_angle_step_plus_noise` の長軸角解析は維持する。

## 背景と判断

速度ノイズ対照では、各フレーム区間の `ω_i=μ+ξ_i`、`ξ_i~N(0,σ²)` を独立に生成している。角度を積分してから差分で速度へ戻す操作はこの対照の評価に不要であり、角度図の折返しが周期速度のように見える。したがって区間末尾のフレームに生成速度を対応付け、最初のフレームの速度は欠測とする。角度・長軸角・推定位相は作らず、生成速度を直接、絶対値化、Gaussian窓SD/Mean、標準化FFT、固定帯域比に渡す。9パネル図の元の角度枠は空欄とし、角度が生成されない旨をタイトルに示す。

平均速度とSDの校正元3細胞、既定fps・時間・seed、独立な乱数列はADR 0017の定義を維持する。実測・角度誤差対照の角速度は引き続き180°長軸角から算出する。保存時系列では直接生成した速度と解析入力の速度を明示し、角度列は保存しない。複数seedの帰無対照も直接速度を解析する。FFTなど下流の数値出力と実行履歴は同じ形式で保存する。

## 代替案

角度積分・再差分を残す案は、角度図とモデル解釈が紛らわしいため採らない。両モデルとも速度を直接生成する案は、角度測定誤差の差分による相関を失うため採らない。

## 影響と限界

直接速度モデルは実測の長軸角測定・180°折返し・画像追跡誤差を経ない。両合成モデルは同じ速度水準へ校正するが、生成過程は異なる。最初の区間速度は定義できない。約6秒の有限標本と絶対値化により実現値は目標値と一致しない。旧角度積分版のローカル図・表は再生成で置き換える。

## 検証

合成テストで速度の独立性、平均・SD、先頭速度欠測、角度列の欠如、角度パネルに描画要素がないこと、解析入力と生成速度の一致を確認する。複数seedのFFT評価も直接速度を使うことを確認し、クリーンなコミットからローカル図・表と依存する5条件比較を再生成する。
