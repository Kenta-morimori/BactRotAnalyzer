# ADR 0007: データセット単位の既定画像入力設定

- 状態: 採用
- 置換する判断: ADR 0005のJSONパス・CLI入力源の毎回の明示必須。

## 決定

- 既定JSONはdata/<day>/repellent_input.jsonとする。設定作成・対話確認・背景登録ではdayを指定すればJSONパスを省略できる。
- 解析では明示JSONを優先し、なければ既定JSONを読む。入力源は保存されたsourceから取得する。CLIでも指定された場合は一致を要求する。
- 既定JSONがなければ従来のAVI入口を維持する。入力源だけを指定して設定がない場合は設定作成を案内して停止する。不正な既定JSONを無視して別入口へ切り替えない。
- measurement-inputとresults-bundleは既定JSONの探索対象外とし、明示された再計算・再描画を優先する。
- JSONは既存ファイルを上書きせず作成する。対象・校正・閾値・ROI・撮影順の未確認を自動承認しない。保存先の省略は科学的条件の変更を意味しない。
- 実行履歴も同じ設定解決を使い、実際に選択したJSON・参照画像・背景を記録する。

## 代替と影響

毎回のパス・入力源指定は操作が多いため既定にしない。複数JSONからの推測は曖昧なので、一つの既定ファイルを使用する。方式比較では明示パスを引き続き利用できる。
既定ファイルを置いたデータセットではdayのみの実行がその設定を使うようになる。設定変更はローカル入力として管理し、コードや実測系列をGitへ追加しない。

## 検証

既定なしの互換性、保存sourceの利用、不一致・別dayの拒否、明示パス優先を合成入力で確認する。
実CLIでJSONパスと入力源を省略し、Mean CSVの登録・検出・集約出力・実行履歴まで確認する。
