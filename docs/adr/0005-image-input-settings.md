# ADR 0005: TIFF/AVIの明示入力設定と標準解析への接続

- 状態: 採用

## 背景

生TIFFの対象指定・閾値・ROIと、既存AVIの抽出は異なる入力処理である。
config.iniがない記録でも元時刻から解析できる一方、対象同一性や校正を画像だけから確定できない。
独立TIFF抽出のCSVは元画素座標であり、標準解析用の物理座標・試料メタデータが不足していた。

## 決定

- config.iniは任意とし、ローカルJSONに入力源、元の試料番号と撮影順、校正、解析範囲、対象指定・再指定、固定閾値・固定ROIを保存する。CLIの入力源とJSONの一致を要求する。
- 既存configの撮影順と解析範囲を草案へ引き継ぐ。設定がない場合はフォルダ名順の草案を作り、人の確認まで実行しない。部分選択で試料を再採番しない。
- TIFFの初回対象・各記録境界後の対象は人が指定する。閾値は10倍線形拡大後のマスクで確認し、自動固定ROIを確認・修正して保存する。未確認の設定では実行しない。抽出中の自動再捕捉は既存抽出の規則を維持し、再捕捉行・明示再指定・記録境界を下流で連結しない。
- 座標は元TIFFまたはAVIの画素空間に保持し、その入力源の校正を一度だけ掛けてμmへ変換する。AVI校正をTIFFへ流用しない。元TIFFの接尾辞+1、時刻タグ、欠測理由と記録区間を保持する。時刻欠測をフレームレートで埋めない。
- AVIは同名のTIFF記録と観測数を照合し、AVI内の順序番号とTIFF元フレームを明示的に保存する。画像内容の一致・対象同一性をこの対応だけで保証しない。観測数が違えば推測せず中断する。
- 新しい明示入力経路では、背景輝度と上昇境界はユーザーが提供する。背景補正・輝度抽出・上昇検出を自動実行しない。元フレームと時刻が一致する外部背景CSVと境界がそろった場合だけ前後解析する。既存のconfigによる背景自動解析経路は維持する。
- 抽出中核を再利用し、単位・メタデータを備えた標準measurement manifestへ接続する。中心・3点平均補完・角速度・品質条件は変更しない。主系列と停止測定の分離、CCW正、平滑化なしを維持する。
- キャッシュは入力源・抽出法・校正・対象指定・閾値・ROI・範囲・全入力ハッシュ・コード・実行環境で区別する。背景設定だけの変更は画像再抽出を要求しない。従来AVIキャッシュを更新せず、新経路は既定で入力源別suffixを使う。
- キャッシュは方式別フォルダ内の識別ハッシュ付きファイルとする。結果は従来のフェーズ別集約で、試料別・実行ID別フォルダを追加しない。

## 代替と影響

config.iniへの全設定集約は、再指定点や試料単位の複合設定が複雑になるため採用しない。
撮影順・対象の自動確定は便利だが、試料番号や対象の取り違えを検出できないため採用しない。
固定閾値2000は対話開始時の候補値であり、全記録に承認済みの閾値とはしない。
接触分離・watershed・背景補正や新しい品質基準は導入しない。識別不能は欠測を維持する。
元画像をハッシュ検証するため、キャッシュ利用時もI/Oが必要である。古いmanifestが参照する原画像や設定を変更した場合は再生成を要求する。

## 検証

合成TIFF/AVIで、画素校正、原行・時刻欠測・フレームgap・再捕捉/再指定境界、撮影順未確認時の停止、解析範囲、部分試料選択、外部背景の照合、キャッシュ分離と改変検出を確認する。
既存の標準解析・出力テストを継続し、ラベル有無・details・ファイル一覧の契約を維持する。
実測の対象・閾値・ROIの確認と物理精度の評価は別であり、合成接続テストを実測精度や独立レビューの証明としない。
