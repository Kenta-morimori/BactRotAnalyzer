# ADR 0001: 元観測の保持と回転の符号

- 状態: 採用

## 背景

平滑化や行の詰め直しは、高周波情報・欠測・反転候補の時刻を変える。保存済みの輪郭点平均と領域重心も異なる入力であり、計算済み系列の比較と抽出法の比較を混同できない。

## 決定

- 元フレームと元時刻を保持する。重心・角速度は平滑化しない。
- 角速度は隣接した有効な2フレームの中心相対ベクトルの符号付き角度差を実時間差で割り、右端フレームに保存する。画像座標はy下向きのまま、出力はCCW正・CW負にする。
- 元観測欠測、非連続フレーム、時刻gap、対象・区間の切替、再捕捉をまたぐ中心補完・角速度・反転判定は行わない。
- 抽出方式ごとに `raw_centroid/<method>/` にキャッシュを分け、旧入力を上書きしない。旧新中心比較には同一の重心系列を使用し、その抽出方式を記録する。
- 停止候補・暫定中心の測定を、既存V2主系列の欠測へ混入しない。

## 代替と影響

Savgol等の重心平滑化、角速度の窓内直線近似、欠測行の削除による連結は採用しない。隣接差分はノイズや参照中心の変化の影響を受け、ゼロ横断を物理的反転と即断できない。200 Hzではナイキスト周波数付近の方向折返しにも限界がある。

## 検証

既知方向の合成軌跡、欠測・gap・ID境界、入力不変性を回帰テストで確認する。実測の再現確認は同じ入力の元フレーム、時刻、有限値マスクと値を比較する。再現一致を真値に対する精度改善とは扱わない。
