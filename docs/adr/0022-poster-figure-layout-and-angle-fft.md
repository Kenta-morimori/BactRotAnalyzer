# ADR 0022: ポスター図のレイアウトと折り返し角度FFT

## 状態

2026-11-15 採用。同日改訂し、角度FFTの右縦軸を廃止した。Issue #82 と温度解析 Issue #86 の図表示を更新する。揺らぎの数値定義は ADR 0009、角度表示は ADR 0010、温度の周回角は ADR 0014 に従う。

## 判断

個別図のx-y重心軌跡は縦横の物理尺度と描画枠をそろえて正方形にする。角速度、SD/Mean、標準化系列、FFTは横長にし、図中に重ねる窓幅は0.1、0.5、1.0秒だけとする。6窓幅の計算、CSV、低周波帯域指標とその比較は維持する。Low/High、Lowのみ、Low−Highの帯域パネルはそれぞれ幅:高さを2:3とする。タイトル、軸ラベル、目盛、凡例を拡大する。

SD/Meanと標準化SD/Meanの時系列パネルは、横軸を0秒から記録の最大時刻までに固定する。合成例の0.5秒窓専用パネルにも適用する。

角度が存在する実測・合成例では、表示している `[-π, π)` の折り返し角度の最長連続有効区間を平均値除去後にFFTへかける。角度FFTの生振幅を黒線とし、標準化SD/MeanのFFT生振幅と同じ対数 `Amp` 縦軸に重ねる。右縦軸と追加の倍率・正規化は設けない。これはユーザーが指定した定性的な周波数位置の比較であり、角度FFTの振幅はrad、標準化SD/MeanのFFT振幅は無次元である。直接速度ノイズ対照には角度を生成しないため、黒線は置かない。

## 代替案

- 累積相対角度のFFTは、回転による長期的な傾きと区間開始時の値が強く影響するため、この図の周期比較には用いない。
- 角度FFTに独立した右縦軸を設け、左右で同じ数値範囲を使う旧表示は、指定された単一軸表示へ置き換えた。
- 2系列をそれぞれ最大値で割る表示は周波数形状の比較には適するが、生振幅をそのまま描く要件と異なるため採らない。
- 3窓幅だけを計算してCSVを減らす案は、既存の帯域比較と再現性を損なうため採らない。

## 結果と限界

折り返し角度の鋸歯状波とその高調波は黒線に含まれる。黒線のピークは独立した生物学的振動の証拠ではない。同じ縦軸に異なる単位の生振幅を置くため、線の高さや交差を物理的な強度比較として解釈できない。各系列の周波数位置だけを定性的に見る。図の3窓幅は表示上の選択で、低周波相対強度の6窓幅表に影響しない。

## 検証

合成周期角度で黒線の主ピークと生振幅を確認し、欠測・時刻gapを跨がないことを確認する。単一の対数縦軸に両系列が描かれ、右軸が作られないことをテストする。直接速度対照では黒線がないこと、揺らぎFFTと帯域表の数値が変わらないこと、正方形軌跡と縦長帯域パネル・文字サイズを図で確認する。実測由来の図と数値表はローカルに保持する。
