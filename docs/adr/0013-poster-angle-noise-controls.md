# ADR 0013: ポスター合成対照を長軸角の生成に統一する

## 状態

2026-11-13 採用。Issue #82。ADR 0009・0010・0012の合成座標、周回角速度、角速度への直接ノイズ注入に関する判断を置き換える。実測の測定と帯域定義は変更しない。合成モデルと校正値は2026-11-14に [ADR 0017](0017-poster-empirical-speed-controls.md) で置き換えた。

## 判断

合成対照でも、実測と同じ180°周期の長軸角を入力として隣接フレーム差からCCW正の角速度を求め、絶対値のGaussian窓SD/Mean、z-score、FFT、Low/High・Low・Low−Highを計算する。重心座標を生成せず、合成図・時系列・品質表から座標と周回角速度を除く。合成代表図は位相、符号付き/絶対値角速度、SD/Mean、z-score、FFT、3つの帯域指標の9パネルとする。実測図の12パネルは維持する。

`constant_angle_step_plus_noise` では、フレーム時刻 `t_i=i/fps` に対して `θ_i=2π×8 Hz×t_i+ε_i` とする。`random_angle_noise` では `θ_i=ε_i` とする。両モデルの `ε_i` は各フレーム独立な正規分布 `N(0, (0.01 rad)^2)` で、seedを固定する。観測長軸角は `−θ_i` を180°で折り返したものとする。ノイズは角度に加え、角速度に直接加えない。既定は200/250 fps、6秒、seed 81。乱数のみの複数seed対照も同じ角度生成から作る。

旧モデル名の生成物は新しい合成実行が成功してから除き、合成索引と表は新モデル名へ更新する。実測の手動採否表と図は合成のみの実行では変更しない。

## 代替案

- 角速度へ独立ノイズを直接加えてから角度・座標を生成する従来案は、実測で長軸角から角速度を求める経路と異なるため採らない。
- 0–180°の一様乱数を各フレームの角度にする案は、角度差が折り返し境界に支配され、一定角度変化モデルと同じノイズ強度で比較できないため採らない。
- 重心座標や周回角速度を表示・評価する案は、今回の合成対照の主目的である長軸角解析に寄与しないため採らない。

## 結果と限界

`random_angle_noise` は角度が独立な純粋ノイズで、角速度は隣接角度の差になる。そのため、得られる角速度はフレーム間で独立な白色ノイズではなく、隣接値を共有する。角度ノイズの標準偏差0.01 radは実測から校正した値ではない。理想的な差分の角速度標準偏差は約 `√2×fps×0.01 rad/s` で、200 fpsでは約2.83 rad/s、250 fpsでは約3.54 rad/sとなる。旧モデルの強度比・FFT・seed分布とは数値互換でない。合成では楕円画像の輪郭検出誤差や欠測は再現しないため、生物学的な帰無分布とみなさない。

## 検証

角度ノイズ0で一定角度差から8 Hz相当の長軸角速度が再現されること、ノイズありで角度差に対応する角速度になること、乱数のみで角度の平均回転がないことを合成テストで確認する。4代表図の9パネル、4ケースの帯域表と索引、200/250 fpsのNyquist上限、複数seed対照、旧合成ファイルの整理を確認する。合成だけを再実行し、実測の選択表と代表図が変わらないことを確認する。
