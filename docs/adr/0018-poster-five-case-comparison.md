# 0018: 3実測・2合成の0.5秒窓FFT振幅比較

## 状態

2026-11-14 採用。Issue #84。ADR 0014の6条件選択を置き換える。フィット式、1 Hz等幅帯域、位相乱数化、逆FFTはADR 0016に従う。独立速度ノイズの入力経路は[ADR 0019](0019-poster-direct-speed-control.md)で更新した。

## 背景と決定

ユーザーの候補見直しにより20230607 No.08を比較対象から除く。実測は20230607 No.06、20231005 No.01、20231107 No.06の3細胞とし、合成はADR 0017の実測速度に校正した `constant_angle_step_plus_noise` と `random_speed_noise` の200 fps・seed 81を用いる。前者は角度差から速度を求め、後者はADR 0019に従い直接生成した速度を用いる。各条件について0.5秒窓SD/Mean、同系列のFFT振幅と包絡フィット、ランダム位相逆FFTを3行×5列の15パネルに示す。No.08の個別実測解析は残す。

## 代替案

No.08を6列図に残す案は、候補から除くという採否判断に反するため採らない。旧合成対照の振幅だけを再調整する案は、角度誤差と速度誤差の相関構造を比較できないため採らない。

## 影響と限界

旧6条件図、No.08のフィット感度図・表、および旧ランダム角度対照の表は現在の結果から除く。過去の実行履歴は残す。合成速度は採用3細胞の細胞別平均と細胞内SDを等重みで集計した値で、実験反復間の推定や生物学的な帰無分布を意味しない。20231005 No.01は停止区間を含む。

## 検証

合成入力で5列15パネル、保存済み0.5秒FFTとの一致、フィットと逆FFT振幅の再現、旧出力の除去を確認する。クリーンなコミットからローカルの保存済み測定・合成CSVで再生成し、3実測＋2合成の入力識別と実行履歴を確認する。
