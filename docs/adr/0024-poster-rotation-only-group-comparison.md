# ADR 0024: 回転区間だけの細胞単位比較

## 状態

2026-11-18 採用。ADR 0009・0011の全記録解析とは別の感度解析であり、元の個別図と手動 `selection.csv` は変更しない。

## 背景と判断

全記録の帯域比には停止中の変化が入る。3日付の各AVIは同一実験内の別細胞であり、独立した生物学的反復ではない。温度23°CのSJW46は重心周回角を使うため、長軸角を使う3日付の群統計に混ぜない。2026-11-18の追加判断として、23℃ No.01–07の保存済み温度解析比を正規化図に参考群としてのみ表示し、角度定義と解析区間の違いを図に明記する。温度側は停止除外をせず、FFTでは最長有効連続区間を使うため、30秒の全記録すべてがFFTに入るとは限らない。ユーザー指定により20230607 No.08も除外する。

各細胞の保存済み長軸角と重心座標を元フレーム・時刻のまま読む。停止候補は既存V2のコンパクト運動判定と、0.2秒の長軸角セカント速度の絶対値<1 HzかつV2重心運動RMSが回転中基準中央値の35%以下で持続する区間を併用する。長軸のセカントで失われる前後0.1秒を候補支持範囲として戻し、長さ0.3秒以上かつコンパクトな周期運動の証拠がない場合に停止候補とする。V2のunknownだけでは停止としない。停止の前後0.1秒と欠測・時刻gapを避け、最長の連続観測区間だけを採用する。停止中の平均値補間、区間の連結は行わない。セカントは停止検出に限り、揺らぎには生の長軸角速度を使う。

採用区間では0.1/0.5/1.0秒のGaussian窓による `SD(abs(ω))/Mean(abs(ω))` を1フレームずつ動かして再計算し、有効系列を標準化してFFTにかける。各窓の `0<f<1 Hz` に正の周波数点が3点以上あり、`80≤f<100 Hz` と `60≤f<80 Hz` の平均FFT振幅が正である細胞だけを群統計へ入れる。主指標は低域平均振幅/80–100 Hz高域平均振幅、後者の変更は感度確認とする。区間長、FFT分解能、各帯域の点数、採否理由を私有表へ残す。

群では各細胞に等しい重みを与え、正の帯域比は対数を取った平均から幾何平均と対数尺度のばらつきを求める。形状比較は各細胞の3窓幅内最大値を1とする。正規化図は各条件・窓幅の細胞分布を箱ひげで示し、算術平均を線で結ぶ。表には算術平均と標準偏差も保存する。日付と条件は完全に対応し、独立実験反復がないため、有意差検定や条件効果の断定は行わない。

採否を監査する図では、全24細胞の切り出し前6秒間の符号付き長軸角速度と、同じ全記録から既に計算した窓幅別Low/High比を横並びにする。別の採否一覧図では、元記録、最長候補区間、最終採用、停止候補を区別する。全記録の比と回転区間だけの比は異なる母集団の指標として混同しない。

## 代替と限界

全回転区間をつなぐ案は、切れ目を跨ぐFFTの偽の低周波成分を作るため採らない。停止を平均速度で埋める案は変動とスペクトルを人為的に変えるため採らない。全細胞で固定長に切る案は利用可能な回転時間を捨てるため採らないが、可変長FFTの分解能は細胞ごとに異なる。停止判定の閾値は探索的であり、AVIの対象・長軸追跡の目視確認が別途必要。200 fps群の80–100 HzはNyquist付近で、250 fps群と帯域位置の相対関係が異なる。60–80 Hz感度図でこれを確認する。群の誤差表示は細胞間の記述的ばらつきであり、実験反復の不確かさではない。

## 検証

合成入力で停止検出、元フレームと欠測を保持した最長区間、短区間の低域点数不足、帯域境界、細胞等重みの集計を確認する。clean Gitコミットから私有の保存済み時系列を解析し、選別表・スペクトル・群図の整合性と元AVIの追跡品質を確認する。実測時系列・図はGitに含めない。
