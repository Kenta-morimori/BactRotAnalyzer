# ADR 0021: SJW46温度解析で局所円錐中心を別出力として比較する

状態: 採用（既存中心の解析は保持）

## 背景

温度別ポスター解析の中心は、標準解析が保存した楕円近似・補正後中心である。忌避応答の既定 `local_conic` と同じ推定法ではない。中心法だけを変えたとき、周回角速度、回転半径、揺らぎの低周波強度がどう変わるかを調べる。

## 決定

- 元の温度出力にある「中心相対重心＋補正後中心」から中心補正前の重心を元フレーム・時刻上で再構成する。config.iniのµm/pxで画素へ戻し、忌避応答の既定 `repellent_workflow.analyze_sample` による `local_conic` 推定と中心補完へ渡す。撮影時刻の正の差の中央値を実測フレーム間隔、保存時刻の精度を1 µsとする。単一AVI内の細胞同一性を仮定する。
- `local_conic` が中心を返せない行は欠測とし、旧中心で埋めない。中心状態・選択窓・モデル次数・レビュー要否を細胞別時系列に残す。下流の周回角、角速度、SD/Mean、FFTと帯域比はADR 0014の定義を再利用する。
- 元の `3_Temperature_Control/` は保持し、新結果をその下の `local_conic/` に保存する。細胞別の旧法・新法差と中心利用可能行数を表にし、温度別の差分図を付ける。

## 代替

元動画から重心を再抽出する方法は、中心法だけの比較でなく重心抽出差も混ざるため採らない。元の温度出力を上書きする方法は、基準との比較可能性を失うため採らない。中心失敗時に旧中心を使う方法は両法の混合になるため採らない。

## 影響・限界

この比較は保存済み重心に依存し、当時の輪郭抽出の妥当性を検証しない。元中心の欠測で元重心を復元できない行も、新法の入力にできない。`local_conic` の診断通過は実験の物理回転軸の真値精度を保証しない。両法で中心利用可能行が変わるため、細胞平均差には中心位置と有効観測の変化が共に含まれ得る。温度間の有意差を主張しない。

## 検証

合成軌道で画素・µm換算、元フレーム・時刻・重心の同一性、欠測の保持、推定中心の妥当性を確認する。実測33細胞では旧出力を変更せず、中心状態、有効速度数、細胞別差分、図と実行履歴を確認する。実測由来の図・表はGitへ含めない。
