# ADR 0015: 0.5秒窓FFT振幅の可変指数包絡フィット

## 状態

2026-11-13 採用、同日[ADR 0016](0016-poster-equal-frequency-fit.md)で主フィットの帯域定義と図の表示を置換。Issue #84。ADR 0014の固定 `A/(f+1 Hz)` と線形振幅最小二乗を置き換えた。入力条件、乱数位相、逆FFTの正規化とDC・終端ビンの扱いは継続する。

## 判断

保存済みの0.5秒窓SD/Meanの標準化系列FFTから、正かつNyquist未満の周波数と正の振幅を取る。最初の正周波数を `Δf=1/T_FFT` とし、正周波数範囲を9つの等間隔な対数周波数帯に分ける。各帯の周波数は幾何平均、振幅は中央値、FFT点数も保存する。空帯域は除く。

振幅包絡を `M(f)=A*((f+Δf)/(1 Hz))^(-α)`、`A>0`、`α>=0` とする。帯域中央値の対数振幅とモデルの対数振幅の残差二乗和を、各非空帯域に同じ重みを与えて最小化する。`Δf` は観測時間から固定し、追加の自由パラメータにはしない。図には元のFFT、フィットに使う帯域中央値、モデルの曲線を重ね、周波数を線形、振幅を対数軸で示す。A、α、Δf、帯域中央値の対数振幅でのR²を表示する。

逆FFTには全正周波数ビンで評価したモデル振幅を使う。位相はケース別の固定seedから独立に生成し、既存の片側FFT振幅規約で再FFTして一致を確認する。これを「観測された揺らぎ指標のスペクトルに合わせた代理系列」と呼び、標準的な電力1/fのピンクノイズとは区別する。

## 代替案

- 固定 `A/(f+1 Hz)` の線形振幅最小二乗は低周波の大振幅点に強く引かれ、高周波では元FFTから離れる。図の対数表示だけではこの差は変わらない。
- 低周波オフセットと高周波床も自由に推定する多パラメータ式は約5.5秒の短いFFTで不安定になりやすいため、まずAとαの2パラメータに限る。
- FFT生点を等重みで対数フィットすると点数の多い高周波帯が支配的になるため、対数周波数帯の中央値を等重みにする。

## 結果と限界

9帯域への集約は狭帯域ピークを平滑化する。モデルはノイズ包絡を表すための記述式で、ピークや停止時刻を再現しない。0.5秒のGaussian窓とSD/Meanの非線形変換がスペクトルに影響するので、推定したαを元の角速度のノイズ指数や生物学的な1/f過程と解釈しない。合成対照でも似た傾きが生じ得る。逆FFT結果は角速度や角度ではなく、標準化SD/Meanに対応する符号付き代理系列である。実測由来の図・時系列・係数はローカルのみに保存する。
