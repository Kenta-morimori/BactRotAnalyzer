# ADR 0025: ポスター用忌避応答の上昇前後比較

- 状態: 採用（研究用の診断比較）

## 背景

一次選別済みの忌避応答細胞について、背景輝度上昇前の回転揺らぎと上昇後の方向符号変化を並べる。元の保存系列には局所中心補完や重心追跡の外れ点があり、欠測を詰めるとFFTと切替回数を誤る。

## 決定

採用細胞、解析区間、輝度上昇境界、確認した重心追跡失敗の元フレーム範囲は、Gitに載せないローカル入力manifestで指定する。保存済みの主角速度（CCW正）を使い、中心・角速度の再推定や平滑化はしない。追跡失敗の重心と、そのフレームを端点に持つ角速度を欠測にする。元フレーム・時刻・既存の欠測を保持し、欠測や記録gapを越えて差分・切替を計算しない。大きな半径逸脱の自動検出は確認候補の出力だけとし、未確認点を自動的に削除しない。

上昇前は `poster_fluctuation.analyze` のGaussian重み付き `SD(|ω|)/Mean` を0.1、0.2、0.5、1.0、1.5、2.0秒で計算し、標準化系列の最長連続区間をFFTに使う。低周波相対強度は、既存ポスター定義の **0<f<1 Hz** の平均FFT振幅を **80≤f<100 Hz** の平均FFT振幅で割る。基準帯が得られない場合は欠測とする。前区間の長さと実際のFFT標本数を結果に残す。

上昇後は、元の連続する隣接2フレームで主角速度がともに有限・非ゼロであるときだけ、符号変化を1回数える。全変化数を適格な隣接時間の合計秒数で割り、1観測秒当たりの診断値を出す。1秒ごとの非重複時間窓も診断時系列として保存する。これは生物学的な回転方向反転の確定数ではない。

確認図には、上昇前後を通した1秒幅の中心付き時間窓を元の各フレームで1フレームずつ動かした符号変化率も示す。各窓で有効な隣接符号変化数をその窓の適格観測秒で割る。解析区間の端で1秒幅が確保できない窓と、中心フレームの主角速度が欠測の窓は表示しない。元フレーム・時刻、窓ごとの変化数と適格観測秒をCSVに残す。この重複窓系列は変化の時期を見る診断図であり、上昇後の全体代表値には使わない。

## 代替・影響・限界

欠損区間の補間は人工的な揺らぎや切替を生むため採らない。重なった1秒スライド窓の平均は同じ切替を多数回数えるため、全体の代表値には使わない。欠損により窓内の適格観測時間が1秒未満になる場合でも、値とその分母を保存する。短い符号反転を除外する持続時間・回転量閾値は今回導入しない。したがって報告値には位置推定ノイズ由来の反転も含む。条件間の前区間長・後区間長、FFT周波数分解能、中心補完率は異なるため、図は記述的比較である。

## 検証

合成系列で元フレーム・時刻の保存、追跡失敗の前後速度欠測、元フレームgapを越えない符号判定、適格観測秒の分母、スライド窓が1フレーム刻みで元時刻に対応することを確認する。実測の確認用図はローカルのみで点検し、実測座標・時系列・図をGit管理しない。
