# ADR 0014: SJW46温度条件の周回角・揺らぎ比較

## 状態

2026-11-13 採用。Issue #86。ポスターの温度条件別解析に適用する。長軸角を用いた他の3実験の定義は変更しない。

## 背景と判断

旧 `outputs/SJW46_temp=10/23/30` の `centroid_coordinate.csv` は補正後回転中心を引いた座標（µm）である。補正後中心CSVを足して画像上の絶対重心を復元する。元CSVの時刻・フレーム行は維持し、補正前と補正後中心の差がある行を記録する。今回は既存の重心・中心を再使用し、元動画から再推定しない。

各フレームの周回角を `atan2(-centered_y, centered_x)` の `[-π,π)` で定義する。画像のy軸は下向きなので、この符号なら反時計回りが正となる。角速度は隣接する有効な角度の最短折返し差を実時刻差で割る。欠測または通常フレーム間隔の1.5倍を超える時刻gapをまたぐ差分を作らない。絶対値角速度を速さとし、細胞ごとの平均角速度はその有効フレーム平均とする。平均回転半径は中心から重心までの距離の有効フレーム平均とする。

揺らぎは [ADR 0009](0009-poster-long-axis-fluctuation.md) の6種類のGaussian窓、1フレームスライド、`SD(abs(ω))/Mean(abs(ω))`、全有効系列のz-score、最長連続有効区間のFFTを周回角速度に適用する。窓幅ごとの相対低周波強度は [ADR 0011](0011-poster-fixed-band-ratio.md) と同じく、`0<f<1 Hz` の平均FFT振幅を `80<=f<100 Hz` の平均FFT振幅で割る。温度別比較では個々の細胞を残して細胞平均も描き、平均速さ対強度の散布図には0.5秒窓を使う。

## 代替案

- 旧 `rot_df.csv` の先頭3 FFT点と80 Hz以上の比は窓幅ごとに低域の実周波数が異なるので採らない。
- 符号付き角速度の平均は正逆回転で相殺するため、速さとして絶対値平均を使う。
- 元動画の再追跡は既存の中心補正と重心算出条件を変えうるため、今回の再集計では行わない。

## 結果と限界

3温度の同じ帯域と窓幅を比較できる。元の中心推定・補正の妥当性はこの再解析では検証できない。角度の最短差分はフレーム間の真の回転がπ以上なら回転回数を復元できない。個々の細胞は実験反復と確認されていないため、温度差の統計的有意性は主張しない。窓幅によりFFTの有効区間と周波数分解能は変わる。

## 検証

合成した中心相対座標から絶対重心と半径を復元する試験、既知の反時計回り角速度と時刻gap・欠測の試験、1秒内の1フレームスライドの点数、合成図と温度別比較図の生成を確認する。実測由来の時系列・図はローカルに保持する。
