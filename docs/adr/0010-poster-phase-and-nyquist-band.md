# ADR 0010: ポスター解析の回転位相とNyquist帯域

## 状態

2026-11-13 採用。Issue #82。ADR 0009 の実測比較系列、角度図、FFT表示・乱数対照の周波数帯を更新する。

## 判断

3日付とも当面は既存の二値AVIを入力にする。元TIFFとの対応確認とTIFFからの再解析は別の判断とし、AVI測定をTIFF原画像の測定と呼ばない。実測の揺らぎ・FFTには菌体長軸から求めた角速度だけを使い、重心周回角速度とその揺らぎ・FFTは実測出力から除く。合成では、生成座標から中心と周回角速度を再推定して真値との誤差を検査するが、揺らぎ・FFTには使わない。

長軸角は180°周期で隣接フレームの最短角度差を積み上げ、連続区間ごとに0から始まる相対角度を得る。角速度計算と数値表にはこの連続した相対角度を保持する。図では相対角度を `[-π, π)` に折り返した推定回転位相を示し、折り返し点と欠測点を線で接続しない。頭尾の向きは識別されたものと解釈しない。符号付き長軸角速度とその絶対値は別パネルに描く。

各図のFFT横軸上限は入力Frame Rateの半分とし、200 fpsは100 Hz、250 fpsは125 Hzとする。既存FFTが返す正の周波数点はDCとNyquist点を含まず、この上限未満にある。振幅は対数目盛りのまま表示する。乱数のみの対照の最大振幅とピーク/中央値比も同じ正の全FFT帯域で計算し、0–20 Hzに固定された列名を全帯域の列名に変更する。Gaussian窓の1フレーム刻み、6窓幅、SD(abs(長軸角速度))/Mean(abs(長軸角速度))、z-score、最長連続区間FFTは維持する。

## 代替案

- 0–20 Hzの固定表示と対照帯域は、実測・文献に根拠がなく、Frame Rateが異なる入力を同じ上限で切るため採らない。
- 元の長軸角を `[-π/2, π/2)` に表示する案は、希望する回転位相を示さないため採らない。頭尾を推定して物理的な `[-π, π)` の向きと呼ぶ案は、頭尾識別の根拠がないため採らない。
- TIFFを直ちに主入力にする案は、20230607の同日付フォルダにTIFFがなく、AVIとの対応も未検証のため今回採らない。

## 結果と限界

Nyquist周波数は規則的な標本化の上限であり、その帯域まで追跡誤差が小さいことや振動性の有意性を保証しない。窓による平滑化と非線形なSD/Meanは周波数ごとの振幅に影響する。全帯域化で乱数対照のピーク/中央値比は旧値と互換でなくなる。長軸の180°対称性により1フレームで90°以上の真の回転は同定できず、折り返し位相は連続性を仮定した表示である。変更後の表から実測の周回角列、周回角FFT、周回角品質指標はなくなる。

## 検証

合成200/250 fpsでFFT図上限100/125 Hzと全帯域対照を確認する。位相の折り返し・欠測で線をつながず、符号付き/絶対値角速度を別図に表示することを確認する。実測24細胞のAVI再実行では、長軸の揺らぎ・FFT数値が旧出力と一致すること、手動採否表と実行履歴が保持されることをローカルで確認する。実測図・系列はGitHubへ掲載しない。
