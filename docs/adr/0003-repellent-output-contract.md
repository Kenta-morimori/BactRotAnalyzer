# ADR 0003: フェーズ別出力と再実行契約

- 状態: 採用

## 背景

試料別・実行ID別の図や複製図はファイルを増やし、何を見ればよいか分かりにくい。再描画の成功だけでは、中心推定から再計算できることを保証できない。

## 決定

`outputs/[suffix/]<day>/repellent_response/` の固定したフェーズ別構成を用いる。試料ごとのディレクトリと実行IDは作らず、CSVは全試料を集約し、図は複数試料をページ分割する。重心・中心・角速度の全期間図はラベル有無の両方を保存し、位置はμm、角速度はrad/s、角速度図に0線を入れる。

`details/` は補正前中心と指定範囲の拡大図に限定する。1/3/5点等の手法選択比較は含めない。ファイル一覧・設定・入力識別情報を保存する。既存manifestが管理する旧出力だけを更新・整理し、入力・未知のファイルを一括削除しない。

従来どおり、背景輝度上昇の元フレームを境界として、前は揺らぎ・FFT、後は切替候補の診断を行う。背景境界と回転方向の切替は別の事象である。上昇境界がなければ前後解析は未実行とし、ゼロ結果を作らない。

SDは元観測ごとのスライド窓で求める。従来のGaussian重み、SD/平均、窓幅、標準化、低周波・80 Hz以上の参照成分の定義を維持する。FFTの表示は両対数にし、表示できないゼロ・非正値のbinも数値表では保持する。入力欠測・gap・推定領域の境界で支持を分け、FFTに用いた連続区間とサンプル数を保存する。

`--measurement-input` は入力重心・校正・撮影メタデータ・背景境界から中心、補完、角速度、SD、FFTを再計算する。`--results-bundle` は既計算値の再出力のみを行う。両者は同時指定できない。入力・設定が同じなら数値・欠測・元フレーム対応が再現することを確認する。実行日時等の管理情報は一致対象に含めない。

切替候補の符号変化率は診断値であり、物理的反転頻度とは区別する。物理的反転・安定化時間が未採用なら未判定を明示する。

## 代替と影響

実行IDによる全履歴保存は標準にしない。履歴を比較する場合は利用者が明示したsuffixを使う。FFTの表示変更によってスペクトル値・特徴量は変更しない。実測の図・系列・Wordはローカルに保持し、PRへ含めない。

## 検証

出力manifestと実ファイルの一致、ラベル有無、ページ分割、0線、log軸、数値保存、再出力時の未知ファイル保持をテストする。入力からの再計算は別に確認する。
