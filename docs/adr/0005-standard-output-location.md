# ADR 0005: 標準回転解析の保存先

状態: 採用

## 背景

標準回転解析と忌避応答解析の結果が `outputs/<day>/` に混在し、忌避応答の結果が見つけにくい。標準回転解析は同じ保存ルートを重心、中心、角速度、揺らぎ、キャッシュ読込に使用する。一方、両解析は方式別の元フレーム重心キャッシュを共用する。

## 決定

標準回転解析CLIの既定結果先を `outputs/rotation_analysis/<day>/` とし、`--output-root` でこの親ディレクトリを指定可能にする。標準解析の時刻、中心相対重心、中心、角速度、揺らぎ、標準解析専用manifestは同じ結果先へ置く。元フレーム重心キャッシュだけは従来の `outputs/<day>/raw_centroid/<method>/` に保持し、忌避応答と共有する。忌避応答のフェーズ別出力、suffix、再実行契約は変更しない。旧標準解析結果は自動移動せず、既存の比較CLIは新しい結果先を優先し、なければ旧結果を読み取り専用で利用する。比較図の保存先は `outputs/rotation_analysis/comparisons/<対象名>/`、温度別角速度集計は `outputs/rotation_analysis/03_av_analysis/` とし、両CLIでも `--output-root` を使用する。

## 代替

- 全解析のルートを一括移動する案は、忌避応答の再実行契約と既存入力manifestを変更するため採らない。
- 旧結果を自動移動する案は、実測の入力同一性や過去の参照を変えるため採らない。

## 影響と限界

既存の `outputs/<day>/` は旧結果と共用キャッシュの参照先として残る。新しい結果先を指定した実行は旧結果を上書きしない。結果先の変更は測定定義や符号を変更しない。過去の図・CSVの削除は個別の参照・保存価値の確認を要する。

## 検証

合成入力で結果先、共有キャッシュ、旧結果の読取優先順位、実行ログの入力・出力を確認する。忌避応答の既存出力構成と共有キャッシュの回帰テストを実行する。
