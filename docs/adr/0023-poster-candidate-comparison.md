# ADR 0023: 代表細胞の帯域指標を最大値で正規化して比較する

## 状態

2026-11-15 採用。ADR 0011 の候補比較図を拡張する。個別細胞の帯域指標の計算定義は変更しない。

## 背景と判断

候補比較図には、20231005 No.01、20230607 No.06、20231107 No.06に加え、温度23°CのSJW46 No.06を載せる。順序と表示名はSJW46: 23°C、SJW46/MotAB、YSC2123/MotAB、YcgR-tetとする。20230607 No.08は候補から除いたままとする。

2026-11-15の表示改訂では、図の凡例だけ先頭を「SJW46」と省略して4条件を図の右外側に縦に並べる。CSVの条件名「SJW46: 23°C」は温度を識別できるよう維持する。図の3つの縦軸は `Amp ratio`、横軸は `Window width [s]` とする。正規化方法と生値は変えない。

6種類の窓幅は比較図で等間隔の離散位置に置き、横軸に実際の秒数を表示する。0.1秒と0.2秒の目盛りの重なりを避けるための表示上の変更であり、横方向の距離を秒数の差として読まない。CSVの窓幅と各指標の値は変えない。
比較図のキャンバス横幅と各パネルの横幅を従来の約1.5倍にする。縦幅と数値系列は変えない。

Low/High、Lowのみ、Low−Highの各指標について、各細胞の6窓幅系列をその系列の有限な最大値で除する。比較図の縦軸は線形目盛りとし、各系列の最大値を1にそろえる。元の値と正規化値を比較CSVに併記する。最大値が正でないか6窓幅がそろわない系列は生成時にエラーとする。

温度23°Cの系列は温度解析の保存済み中心を使う重心周回角から計算した揺らぎ、他の3系列は菌体長軸角から計算した揺らぎである。図中とCSVに角度定義を明記する。温度解析の帯域表がまだ存在しない場合は3細胞の比較を作り、表が得られた後の再実行で4系列とする。実測3細胞のPNGには条件名と `representative` をファイル名に加え、索引の `plot_file` に反映する。

## 代替と影響

0.5秒窓を基準にする案では基準点への依存が強いため、各系列の最大値を基準にする。元の値を同一縦軸で比較する案は規模差によって形が見えにくいため採らない。正規化図から絶対振幅の大小は判断できない。また、異なる角度定義による系列は同じ生物学的指標として直接比較できない。20231005 No.01は停止を含む全記録であり、その影響が残る。

## 検証

合成表で3指標ごと・細胞ごとに最大値が1になること、元の値が変わらないこと、4系列の凡例順と角度定義を確認する。実データの図・表はローカルに保存し、GitHubへ掲載しない。
