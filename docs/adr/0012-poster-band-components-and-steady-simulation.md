# ADR 0012: ポスター解析の帯域成分表示と非周期の合成角速度

## 状態

2026-11-13 採用。Issue #82。ADR 0011の強度比出力を拡張し、ADR 0009の周期変調を含む合成条件を置き換える。

## 判断

実測と合成代表例の各窓幅について、ADR 0011の `Low / High` に加えて、`Low = mean(A(f), 0 < f < 1 Hz)` と `Low − High = Low − mean(A(f), 80 <= f < 100 Hz)` を同じPNGの最下段に横並びで描く。候補4細胞の比較PNGも3パネルとする。`Low / High` は縦軸対数、`Low` と `Low − High` は縦軸線形とし、差が負になっても表示する。既存の比表に差の列を加え、低域・高域の平均振幅と使用FFT点数は保持する。合成代表例にもケース別の帯域表を保存し、合成 `index.csv` から参照する。実測の停止を含む注記は実測図だけに付ける。

合成角速度への決定論的な2 Hz正弦波変調を廃止する。新しい `steady_rotation_plus_noise` は、各フレームで `ω_i = 2π × 8 Hz + ε_i`、`ε_i` は独立な正規分布 `N(0, (3 rad/s)^2)` からseed固定で生成する。角度は角速度を積分し、半径0.5 µmの円軌道座標 `x=0.5 cos θ`、画像下向きyに対応する `y=−0.5 sin θ` を作り、各座標に独立な正規ノイズ（標準偏差0.01 µm）を加える。もう一方の `random_only` は平均回転0 Hz、同じ角速度ノイズと座標ノイズを使う。既定の撮影レートは200/250 fps、長さ6秒、seed 81。元の周期変調モデルの生成ファイルは新モデルの出力後に除く。

## 代替案

- 2 Hzの周期変調を残す案は、長い窓ほどSD/Meanが増える原因となり、利用者の求める非周期角速度の対照に合わない。
- 回転角度や座標の周期性をなくす案は、テザードセルの周回座標から角速度を再推定する検証目的を失う。平均回転は維持し、角速度の周期変調だけをなくす。
- `Low − High` の対数表示は負値を表せないため採らない。

## 結果と限界

一定平均速度の円周運動なので座標は周回するが、角速度には指定した周期の変調を含まない。有限長の白色ノイズから見かけのFFTピークは生じ得る。フレームごと独立なノイズは実測の時間相関を再現しない。窓幅間のSD/Meanの完全一致や実測との分布一致を保証せず、合成を生物学的帰無分布として使わない。旧 `periodic_plus_noise` の時系列・FFTとは数値互換でなくなる。

## 検証

ノイズ標準偏差0の合成角速度が200/250 fpsの全フレームで一定になることを確認する。seed固定のノイズ付き合成について6窓幅のSD/Meanを比較し、長い窓だけが大きくなる状態が解消したことを確認する。合成の真値と再推定値、乱数のみ対照、実測・合成の12パネル表示と帯域表・一覧の参照、旧合成ファイルの整理を検証する。実測由来の図・系列はGitHubへ掲載しない。
