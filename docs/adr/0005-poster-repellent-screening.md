# ADR 0005: ポスター用忌避応答候補の一次選別

状態: 採用（一次選別のみ）

## 背景

ポスター向けに、中心が不連続に移動しない、背景輝度が上昇する、記録時間の過半で回転が続く細胞を探す。既存の忌避応答出力には解析モード違いの同一試料と、元データだけが存在する群が混在する。停止の物理判定と輝度立ち上がりの刺激到達時刻は未確定である。

## 決定

- 既存の試料別出力を元の試料番号で扱い、既知の再出力を独立細胞に数えない。未処理の原データは未評価として一覧へ残す。
- 重心相対座標・中心、輸出済みの角度・角速度、背景輝度をそれぞれ元の時刻軸で表示する。欠測・時刻gapを跨いで線を結ばず、中心の隣接有効評価点の変位を軌道半径中央値で割って参考表示する。
- 旧出力で角速度が角度より1点短い場合は、既存出力契約に従い各差分区間の開始時刻へ対応させる。同数の場合は各点の時刻を使う。角速度の時刻や値を補間・再計算しない。
- 背景上昇点は既存出力の値を表示するが、刺激到達時刻とはみなさない。上昇前後の背景中央値比を参考値として保存する。
- 停止判定は確定しない。輸出済みの絶対角速度が上昇前中央値の0.1/0.2/0.3倍以上である割合を一次選別の参考値とする。観測点の割合に加え、隣接時刻の有効な区間を積算した時間割合を保存する。時刻gapを跨ぐ区間は回転時間へ加えず、全記録の経過時間を分母とする「回転を示せた時間の下限」と、有効区間だけを分母とする割合を併記する。欠測を非停止へ補充しない。過半数条件の最終解釈は図を見たユーザー確認後に決める。
- 目視確認の順番を付けるため、背景中央値比1.5以上、中心の最大隣接移動が軌道半径中央値の0.1倍以下、速度の全記録時間に対する下限割合が0.5超の試料を `review_first.csv` に抽出する。採用判定ではなく、残りも一覧に保持する。

## 代替案

全原TIFFを直ちに再解析する方法は、未処理群が多く、中心手法と計算負荷の確認が必要なため保留した。既存の停止検出時刻を記録全体の停止率とみなす案は、単一の停止開始候補であり、観測時間の割合を表さないため採用しない。任意の速度閾値による自動採否も行わない。

## 影響・限界

旧出力に設定記録がない場合は中心手法を特定できない。元データフォルダとの対応が不明な群は出所確認が必要である。速度の閾値比は既存の空間活動量による停止検出とは異なり、物理的な停止率ではない。点の角速度を次の観測区間へ割り当てる時間割合は近似であり、欠測区間は下限側に扱う。中心の変位指標も実際の中心誤差を証明しない。上昇前の揺らぎと上昇後の切替評価は次段階で行う。実測由来の図・系列はローカルにのみ保存する。

## 検証

合成系列で欠測中心を跨がないこと、輝度の前後比、欠測速度を非停止へ補充しない割合を確認する。実測では一覧の元試料番号・出力参照・図の時刻と欠測を目視確認し、定性評価を依頼する。
