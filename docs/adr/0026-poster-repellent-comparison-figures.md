# ADR 0026: 忌避応答の比較図を単独で出力する

- 状態: 採用（ADR 0025の比較PNGを出力しない判断を置換）

## 背景

上昇前Low/High比と上昇後の符号変化率をポスターに別々の位置・大きさで配置したい。結合図は切り出しにくく、重複する散布図も不要である。

## 決定

窓幅別Low/High比と、0.5秒窓の上昇前Low/High比対上昇後符号変化率を別のPNGにする。どちらも試料名の凡例・点ラベルを付けず、軸名・単位・目盛りは残す。代表試料はCLIの `--representative-case-id` で指定し、現在のポスターでは `23_No08` を使う。試料別数値と対応関係は従来どおりローカルの集計CSVに残す。結合図と旧単独散布図は生成しない。

## 代替・影響・限界

結合図と凡例付き図は試料識別が容易だが、ポスター上の配置と表示サイズを制限する。凡例なし図単独では点と試料の対応を確定できないため、定量的な解釈には集計CSVを用いる。測定値、マスク、前後の区間、符号変化の算出方法は変更しない。

## 検証

合成集計表で2つのPNGの生成と軸・点数を確認し、実測を再実行して代表試料図と比較図を目視確認する。実測図・時系列はGitに含めない。
