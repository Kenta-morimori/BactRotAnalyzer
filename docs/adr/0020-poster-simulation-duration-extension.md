# ADR 0020: 合成対照に30秒系列を追加する

## 状態

2026-11-14 採用。Issue #82、PR #83。ADR 0017・0019の合成モデルと校正は維持し、合成代表例の時間長と出力契約を拡張する。

## 背景と決定

6秒系列だけでは、より長い観測での揺らぎFFTと低周波帯域を確認できない。角度誤差対照と直接速度ノイズ対照のそれぞれについて、従来の200/250 fps・6秒・seed 81の出力を保持し、同じfps・seed・校正値による30秒系列を追加する。30秒系列は `simulation_<model>_<fps>hz_30s_seed<seed>` をファイル名の基礎とし、6秒系列の既存名には時間長を付けない。`index.csv` に時間長を各行で明記する。

CLIは主時間長 `--synthetic-duration` の既定6秒に加え、`--additional-synthetic-durations` の既定30秒を実行する。いずれも正の有限値かつ相互に異なる値を要求する。複数seedのランダム速度ノイズ集計は従来どおり主時間長6秒を用いる。0.5秒窓の5条件1/f比較も既存6秒入力を用い、30秒系列を自動的には追加しない。

## 代替案

既存の6秒ファイルを30秒で上書きする案は、過去の図・CSVと5条件比較の入力同一性を失うため採らない。30秒だけに置換する案は、観測時間による違いを確認できなくなるため採らない。

## 影響と限界

30秒系列は6秒と同じseedの乱数列を先頭から使うため、独立した反復ではない。角度誤差対照は長軸角から速度を求め、直接速度ノイズ対照は角度を作らず速度を解析する。FFTの周波数刻みと低周波ビン数は有効な窓系列長に従って変化する。6秒と30秒のFFT振幅・帯域比の差を独立な生物学的差として解釈しない。

## 検証

合成テストで6秒の既存名、追加時間長の識別名、両モデル・両fpsのindex行と時系列長、6秒の複数seed集計を確認する。クリーンなコミットからローカルの30秒4図・表を生成し、6秒4図・5条件比較・手動選択表を保持する。
