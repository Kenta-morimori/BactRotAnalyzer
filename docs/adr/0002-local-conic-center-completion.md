# ADR 0002: 局所中心推定と3点平均による暫定補完

- 状態: 採用（研究用の暫定参照。実測物理中心の精度保証ではない）

## 背景

停止・短い回転弧では中心が識別できない。一方、全期間固定中心ではドリフトに対応できない。推定に成功した値と、前後の情報から仮定義した値を区別して停止・反転付近を表示する必要がある。

## 決定

局所の楕円軌道・時間変化モデル `local-conic-2d-provisional-v1` を用いる。支持窓は0.2/0.4/0.8/1.6/3.2/6.4秒、中心の時間多項式は1次・2次を候補とする。各窓は元観測の全点を使い、共通の局所検証点による予測残差と中心の条件付き誤差尺度で選択する。中心評価は20フレームごとのアンカーと連続区間の端で行い、その間は制限付き短区間補間とする。角速度・重心の出力行は間引かない。

共通推定関数の `parameters` 引数で設定を渡す。通常実行へ接続する側では `utils/param.py` の `repellent_center_parameters` を設定窓口とする。条件付き誤差尺度0.05、相対残差0.3、倍率2.45、検証guard 4行、モデル切替時の中心差比0.05は凍結版の値を維持する。これらを実測中心の5%精度保証や信頼確率とは呼ばない。

残る中心欠測には、直前・直後の有限中心ブロックにある直接推定点を各最大3点使う。短区間補間点や別の欠測ブロックを越えた点は支持に使わない。それぞれの座標平均を、その支持点の平均時刻に置き、実時間に対して線形に結ぶ。片側のみならその平均を保持し、両側とも支持がなければ欠測を維持する。3点未満の場合は利用できる点数で計算し、実使用数を保存する。

直接推定、短区間補間、両側平均補完、片側保持、未定義を別ラベルで保存する。補完は有限な既存中心を変更せず、元重心欠測・記録境界を越えない。

## 代替と影響

1/3/5点の比較を経て3点を既定にする。比較専用コード・比較図は標準出力へ持ち込まない。全体中央値や無条件の外挿は用いない。

長い停止中の補完は、前後の中心が滑らかに繋がるという仮定である。補完時間・支持点・距離・接続境界を保存し、中心の正しさや停止・反転を保証しない。中心と半径の同時変化や位相に同期した半径変化は未検証・識別困難な領域として残る。

## 検証

既知中心・ドリフト・楕円の合成例、支持不足、gap、元欠測、ID境界、片側補完、既存中心不変性を確認する。同じ実測入力で凍結版・承認済み補完結果との数値一致を確認し、中心推定と補完を独立に比較する。
