# ADR 0014: 0.5秒窓の1/f振幅フィットと乱数位相の逆FFT

## 状態

2026-11-13 採用。Issue #84。ADR 0013の長軸角を主とする実測・合成出力を入力とする追加解析。

## 判断

実測候補4細胞（20230607 No.06/08、20231005 No.01、20231107 No.06）と、200 fps・seed 81の角度ノイズ対照2種を同じ図の6列に並べる。0.5秒Gaussian窓の生のSD/Mean時系列、標準化SD/MeanのFFT振幅とフィット、逆FFTで生成した系列を3行に配置する。合計18パネル。

各ケースでは既存の0.5秒窓FFTが選んだ最長連続区間を維持する。正の周波数かつNyquist未満の保存済みFFT**振幅**を `A(f)=A/(f+1 Hz)` に、通常の振幅空間で切片なしの最小二乗で当てはめる。係数A、残差、決定係数、周波数とサンプル数を保存する。分母の1 Hzは固定であり、0 Hzで発散しない。これは電力スペクトル密度が1/fの通常のピンクノイズではなく、**1/f形のFFT振幅**に対するモデルである。

フィットした各正周波数ビンに独立な一様乱数位相を与え、seedをケース別に固定する。実数の逆FFTを使い、DCと既存FFTが返さない最後の正周波数ビンを0にする。既存の片側FFT振幅 `2|X_k|/N` と一致するよう、複素係数を `(N/2)A(f_k)e^{iφ_k}` とする。逆FFT結果は平均0の標準化系列の単位で、長さは元の最長連続FFT区間に合わせる。

## 代替案

- 元系列の位相を保持する案は元の山谷の時刻構造を再利用し、新しいノイズ対照にならないため採らない。
- `1/(f+C)` は周波数の曲がり方だけでなく全体振幅もCに束縛される。6秒記録の低周波点数ではオフセットの自由推定も不安定になり得るため、ユーザー確認済みの `A/(f+1 Hz)` を採る。
- PSDの1/fに対応する振幅 `1/√f` は通常のピンクノイズの定義には合うが、今回はFFT**振幅**を1/f形にフィットするユーザー指定を優先する。

## 結果と限界

約6秒の入力でも0.5秒窓のFFT区間は約5.5秒で、最初の正周波数は約0.182 Hz。低周波の形は少数ビンに依存し、1/f形の当てはまりは自動的に保証されない。位相の乱数化で時間上の元データの停止や山谷の位置は保存されない。逆FFT系列は標準化単位の符号付き信号であり、生のSD/Meanや物理的な角速度そのものではない。各ケースの単一seed実現を振動性の統計的有意性とみなさない。実測由来の図・時系列・フィット係数はローカルに留める。

## 検証

合成FFTで係数推定、偶数・奇数長の周波数ビン、seed再現性、逆FFT後の実数性と再FFT振幅一致をテストする。入力時系列と保存済みFFTの対応、元フレーム・時刻、6列×3行の図、既存の実測・合成元出力の不変をローカルで確認する。実行履歴はclean Gitゲートで記録する。
