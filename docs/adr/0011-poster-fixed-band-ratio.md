# ADR 0011: ポスター解析の固定周波数帯強度比

## 状態

2026-11-13 採用。Issue #82。ADR 0010のFFT全帯域表示は維持し、実測の比較指標を追加する。LowとLow−Highの追加表示は [ADR 0012](0012-poster-band-components-and-steady-simulation.md) で更新。

## 判断

実測の各細胞・各Gaussian窓幅について、標準化済み `SD(abs(長軸角速度))/Mean(abs(長軸角速度))` のFFT振幅から、`0 < f < 1 Hz` の平均を `80 <= f < 100 Hz` の平均で割る。DC、非有限の周波数・振幅、負の振幅を除く。帯域に有効点がない場合、または高域平均が0の場合は比を欠測にする。窓幅は従来の0.1/0.2/0.5/1.0/1.5/2.0秒で、FFTの最長連続区間選択も変えない。振幅の和・積分・パワー比・ピーク比ではない。帯域への割当だけ周波数を小数第9位まで丸め、浮動小数点誤差で境界の1 Hzや100 Hzが開区間に入らないようにする。FFTの保存値は丸めない。

全24細胞の日付別 `No.XX.png` に強度比のパネルを加え、日付別 `tables/No.XX_band_amplitude_ratio.csv` に帯域境界、使用点数、両平均振幅、比を記録する。ユーザーが暫定候補とした20230607 No.06・No.08、20231005 No.01、20231107 No.06を1枚の比較図と表にまとめる。手動 `selection.csv` は自動変更せず、候補図を最終採否とみなさない。20231005 No.01を含め、停止区間があっても既存FFTと同じ全時系列を使い、停止の影響を図に明記する。比の図の縦軸は対数目盛りとする。

## 代替案

- 既存 `evaluate_FFT` の「最初の3点 / 80 Hz以上の平均振幅」は、窓幅で低域の実周波数が変わり、200/250 fpsで高域の上端も異なる。4細胞を同じ帯域で比較するため採らない。
- 停止区間を除いたFFTは、停止判定と区間分割を新たに要し、既存の全時系列FFTと異なる指標になる。今回の比較には使わない。

## 結果と限界

200/250 fpsの両方で同じ周波数帯を比較できる。ただし6秒の観測と窓による端部欠測のため、低域に含まれるFFT点は少なく、窓幅で周波数刻み・点数が変わる。窓操作、停止、追跡誤差、高周波の測定精度は比に影響する。比が大きいことだけで振動性の有意性や条件差を示せない。候補の各No.は別細胞であり、独立した実験反復としての統計比較を行わない。

## 検証

合成FFTで帯域境界、平均振幅、0振幅・欠測の扱いを確認する。200/250 fpsの合成時系列から実測用の10パネル図、窓幅ごとの表と4細胞比較図を確認する。実測由来の図・系列はローカルに置き、GitHubには載せない。
